Адресная книга позволяет пользователям сохранять ID устройств RustDesk, упорядочивать их с помощью меток, делиться списками устройств и подключаться из клиента RustDesk с сохранёнными паролями.

## Коротко

- **Моя адресная книга** видна только вошедшему пользователю. Запомненные пароли, введённые вручную, сохраняются в **Моей адресной книге** и могут синхронизироваться между устройствами пользователя.
- **Общими** адресными книгами можно делиться с конкретными пользователями, группами пользователей или со всеми пользователями.
- В общей адресной книге можно сохранить пароль на уровне адресной книги, а в каждой записи устройства — пароль на уровне устройства. Если пароль устройства не задан, используется пароль адресной книги.
- Метки позволяют фильтровать устройства в веб-консоли и в клиенте RustDesk.

## Подключение в один клик через общую адресную книгу

Используйте общую адресную книгу, если пользователям нужно подключаться, не вводя каждый раз пароль удалённого устройства.

1. Создайте или откройте общую адресную книгу. При желании задайте для неё **пароль на уровне адресной книги**.

2. Нажмите на название адресной книги, чтобы открыть страницу устройств. Нажмите **Import**, выберите устройства для импорта и нажмите **Save** внизу, чтобы сохранить выбранные устройства. Или нажмите **Add**, чтобы добавить устройство по ID (для прямого IP-доступа укажите IP-адрес в качестве ID). При желании задайте **пароль на уровне устройства** для отдельных записей.

3. Поделитесь адресной книгой с конкретными пользователями, группами пользователей или со всеми.

4. Пользователь входит в клиент RustDesk и открывает вкладку **Адресная книга**.

5. Пользователь выбирает общую адресную книгу и нажимает на карточку устройства.

![Нажатие на карточку устройства из общей адресной книги в клиенте](/docs/en/self-host/rustdesk-server-pro/address-book/images/click-peer-card.png)

{{% notice warning %}}
Общий пароль используется, только когда вы подключаетесь из соответствующей общей адресной книги — нажатием на карточку устройства или через её раскрывающееся меню. Он не используется при подключении с другой вкладки устройств, кнопкой **Подключиться** рядом с полем ввода ID или из другой общей адресной книги.
{{% /notice %}}

## Разрешения общей адресной книги

| Разрешение | Что могут пользователи |
| --- | --- |
| **Только чтение** (Read-only) | Просматривать устройства и метки, использовать пароль. |
| **Чтение и запись** (Read/Write) | Изменять устройства и метки. |
| **Полный доступ** (Full Control) | Делиться адресной книгой дальше, удалять или переименовывать её. |

Если к одному пользователю применяется несколько правил, приоритет такой:

1. Пользователь
2. Группа
3. Все

Например, если для **Все** задано «Только чтение», а для конкретного пользователя — «Полный доступ», этот пользователь получит полный доступ.

## Веб-консоль

### Создание и изменение общей адресной книги

В разделе **Address Book > Shared** создайте общую адресную книгу: укажите название, при желании заметку и **Default Shared Password** (общий пароль по умолчанию). Это и есть пароль на уровне адресной книги.

![Создание общей адресной книги с общим паролем по умолчанию](/docs/en/self-host/rustdesk-server-pro/address-book/images/create-shared-address-book.png)

### Добавление устройств и паролей

Устройства можно добавить вручную по ID или импортировать из списка устройств Server Pro. Для каждой записи можно задать псевдоним, метки, заметку, а в общих адресных книгах — ещё и пароль на уровне устройства.

![Добавление устройства в общую адресную книгу](/docs/en/self-host/rustdesk-server-pro/address-book/images/import-device.png)

![Устройства](/docs/en/self-host/rustdesk-server-pro/address-book/images/web-console-addressbook-devices.png)

![Изменение устройства в общей адресной книге](/docs/en/self-host/rustdesk-server-pro/address-book/images/web-console-edit-device.png)

### Метки и фильтрация

Метки упорядочивают и фильтруют устройства. `Untagged` (без метки) показывает устройства без меток. Если включено **Filter by intersection** (фильтр по пересечению), показываются только устройства, у которых есть все выбранные метки.

### Корзина

При удалении устройства из адресной книги запись перемещается в корзину этой адресной книги. Из RustDesk Server Pro само устройство не удаляется.

## Как работает общий пароль

| Уровень пароля | Приоритет |
| --- | --- |
| Пароль на уровне устройства | Используется в первую очередь, если у записи устройства есть пароль. |
| Пароль на уровне адресной книги | Используется, если у записи устройства пароля нет. |

Если не задан ни один из паролей, пользователь подключается как обычно и, возможно, должен будет ввести пароль вручную. В веб-консоли столбцы паролей показывают только то, задан ли пароль.

## Предустановки при развёртывании

В конфигурации клиента RustDesk можно заранее задать назначение адресной книги:

- `preset-address-book-name`
- `preset-address-book-tag`
- `preset-address-book-alias`
- `preset-address-book-password`
- `preset-address-book-note`

Для `preset-address-book-alias`, `preset-address-book-password` и `preset-address-book-note` нужны клиент RustDesk 1.4.3 или новее и RustDesk Server Pro 1.6.6 или новее.

Подробнее см. [расширенные настройки клиента](/docs/ru/self-host/client-configuration/advanced-settings/#preset-address-book-name--preset-address-book-tag--preset-address-book-alias--preset-address-book-password--preset-address-book-note).

## Связанные настройки

| Настройка | Где | Что делает |
| --- | --- | --- |
| **Allow non-admin to share address books to other groups** | **Settings > Others** | Разрешает пользователям без прав администратора делиться адресными книгами с другими группами пользователей. |
| **Disable address book** | **Custom Client** | Скрывает или отключает адресную книгу в созданном собственном клиенте. |

## Устранение неполадок

### Неверный пароль

Пароль, сохранённый в общей адресной книге, использует управляющий клиент RustDesk. На управляемом устройстве он не задаётся. Пароль управляемого устройства задаётся на самом устройстве в разделе **Настройки > Безопасность > Пароль**.

Чтобы использовать общий пароль, подключайтесь из соответствующей общей адресной книги нажатием на карточку устройства. При подключении из другой адресной книги, с другой вкладки устройств или кнопкой **Подключиться** рядом с полем ввода ID общий пароль этой адресной книги не используется.
