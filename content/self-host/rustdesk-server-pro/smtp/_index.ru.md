В этом руководстве описано, как настроить отправку электронной почты из RustDesk Server Pro через SMTP.

После настройки SMTP сервер сможет отправлять уведомления по электронной почте: приглашения пользователям, подтверждения входа и тревоги о подключениях.

## Для чего нужен SMTP в RustDesk Server Pro?

SMTP используется для отправки исходящей почты из RustDesk Server Pro. На практике это обычно письма с приглашениями, коды подтверждения входа и уведомления о тревогах при подключениях.

## Порядок настройки SMTP

1. Выберите SMTP-сервер, который разрешает отправку почты из вашей среды размещения.
2. Подготовьте хост, порт, имя пользователя, пароль и адрес отправителя.
3. Введите эти настройки в веб-консоли RustDesk Server Pro.
4. Отправьте тестовое письмо из консоли, прежде чем включать для пользователей функции, использующие почту.

## Что проверить в первую очередь, если почта не работает?

- Не блокирует ли ваш VPS-провайдер порты `25`, `465` или `587`
- Не требует ли почтовый сервис пароль приложения или отдельные учётные данные для ретрансляции
- Разрешает ли почтовый сервис использовать адрес в поле `From`
- Соответствуют ли TLS и выбранный порт SMTP требованиям почтового сервиса
