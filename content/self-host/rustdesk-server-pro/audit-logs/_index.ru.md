Журналы аудита в веб-консоли RustDesk Server Pro помогают администраторам просматривать действия при удалённом доступе, передачу файлов, изменения в администрировании и тревоги безопасности.

Откройте веб-консоль и перейдите в раздел **Logs** в меню слева. В разделе журналов есть:

- **Connection** (подключения)
- **File** (файлы)
- **Console** (консоль)
- **Alarm** (тревоги)

## Журналы подключений

Откройте **Logs > Connection**, чтобы просмотреть удалённые сеансы и связанные типы подключений.

В журналах подключений показаны:

- **Type**: Remote Desktop (удалённый рабочий стол), File Transfer (передача файлов), Port Transfer (передача портов), View Camera (просмотр камеры), Terminal (терминал) или Not Logged In (вход не выполнен). **Not Logged In** означает, что аутентификация не прошла.
- **Controlled Device**: ID и имя целевого устройства.
- **Controlling Side**: управляющий пользователь, если на управляющей стороне выполнен вход, а также управляющее устройство, его имя и IP-адрес.
- **Start Time**, **End Time** и **Duration** — время начала, время окончания и длительность.
- **Authentication**: основной способ аутентификации и, при наличии, сведения о 2FA.
- **Note** — заметка.

![Страница журналов подключений](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/connection-log-page.png)

Возможные значения основного способа аутентификации:

- Click Confirmation (подтверждение нажатием)
- One-time Password (одноразовый пароль)
- Permanent Password (постоянный пароль)
- Switch Sides (смена сторон)

Возможные значения 2FA:

- 2FA Code (код 2FA)
- Trusted Device (доверенное устройство)

### Заметки к подключениям

Управляющая сторона может добавить заметку к подключению двумя способами:

- Во время удалённого сеанса выберите действие **Note** в меню удалённого сеанса, чтобы добавить или изменить заметку к подключению.

![Окно заметки к подключению](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/note-box.png)

- В конце удалённого сеанса: включите на управляющей стороне **Настройки > Общие > Другое > Запрашивать заметку в конце соединения**, если хотите, чтобы RustDesk просил ввести заметку при завершении сеанса.

![Окно заметки при закрытии подключения](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/close-conn-note-box.png)

Заметка отображается в столбце **Note** в **Logs > Connection**. Пользователи, которые могут просматривать журнал подключений, также могут изменить заметку из веб-консоли кнопкой редактирования в столбце **Note**.

### Разрыв активного подключения

Если подключение ещё активно и у вашей учётной записи есть право изменять эту запись аудита, в столбце **Action** отображается **Disconnect**. Нажмите её и подтвердите действие, чтобы разорвать активное подключение.

![Подтверждение разрыва подключения](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/disconnect-confirm.png)

После разрыва подключения из веб-консоли управляющая сторона видит сообщение о том, что подключение было разорвано из веб-консоли.

![Сообщение о разрыве из консоли](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/disconnected-by-console.png)

## Журналы передачи файлов

Откройте **Logs > File**, чтобы просмотреть действия с передачей файлов.

![Страница журналов передачи файлов](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/file-transfer-logs.png)

В журналы передачи файлов попадают операции с файлами как в отдельных сеансах **File Transfer**, так и при копировании и вставке файлов во время сеансов **Remote Desktop**.

В журналах передачи файлов показаны:

- **Controlled Device** — управляемое устройство.
- **Controlling Side**: управляющее устройство и, при наличии, управляющий пользователь.
- **Time** — время.
- **Direction** — направление:
  - Controlled Device -> Controlling Side (с управляемого устройства на управляющую сторону)
  - Controlling Side -> Controlled Device (с управляющей стороны на управляемое устройство)
- **File**: путь на управляемом устройстве.
- **Detail**: размер файла для одного файла или число файлов при передаче нескольких файлов.

При передаче нескольких файлов нажмите на число файлов в столбце **Detail**, чтобы открыть панель с подробностями. Если файлов больше, чем помещается в список панели, показываются 10 самых больших файлов.

![Подробности передачи файлов](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/file-transfer-details.png)

## Журналы тревог

Откройте **Logs > Alarm**, чтобы просмотреть события, связанные с безопасностью.

![Страница журналов тревог](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/alarm-logs.png)

В журналах тревог показаны:

- **Type** — тип.
- **From**: для тревог учётной записи — устройство, с которого выполнялся вход. Для тревог удалённых подключений — управляющая сторона.
- **Target**: для тревог учётной записи — учётная запись, в которую выполнялся вход. Для тревог удалённых подключений — управляемое устройство.
- **Event Time** — время события.

Типы тревог удалённых подключений:

- Попытка доступа не из белого списка IP
- Более 30 попыток доступа подряд
- Несколько попыток доступа в течение одной минуты
- Слишком много попыток доступа подряд с одного префикса IPv6
- Несколько неудачных попыток входа в терминал с правами администратора (неверное имя пользователя или пароль)
- Несколько одновременных попыток входа в терминал с правами администратора
- Нарушение области действия сеанса

Типы тревог учётных записей:

- Более 30 попыток входа подряд
- Несколько попыток входа в течение одной минуты
- Несколько попыток входа в течение одного часа

## Журналы действий в консоли

Откройте **Logs > Console**, чтобы просмотреть действия, выполненные в веб-консоли.

![Страница журналов действий в консоли](/docs/en/self-host/rustdesk-server-pro/audit-logs/images/console-logs.png)

В журналах консоли показаны:

- **Type** — тип.
- **User**: пользователь веб-консоли, выполнивший действие.
- **Operation**: конкретное действие.
- **Time** — время.
- **Detail**: дополнительные поля, записанные для действия.

Типы:

- Group Management (управление группами)
- User Management (управление пользователями)
- Device Management (управление устройствами)
- Address Book Management (управление адресными книгами)
- Admin Roles Management (управление ролями администраторов)
- Control Roles Management (управление ролями управления)

Отслеживаются, в частности, вход пользователей, изменения пользователей и устройств, отключение устройства, изменения адресных книг, изменения 2FA, сброс пароля, изменения ролей администраторов и ролей управления.

## Видимость и хранение журналов {#log-visibility-and-retention}

Видимость журналов зависит от того, является ли пользователь администратором, есть ли у него [роль администратора](/docs/ru/self-host/rustdesk-server-pro/admin-role/) с разрешениями на журналы аудита, и от настройки в **Settings > Other**.

| Тип пользователя или настройка | Видимость журналов |
| --- | --- |
| Администратор | Видит все журналы аудита. |
| Роль администратора с **Global > Audit Logs-View** | Видит все журналы аудита, даже если включено **Only admin can access logs**. |
| Роль администратора с **Individual > Audit Logs-View** | Видит личные журналы аудита, даже если включено **Only admin can access logs**. Это тот же объём личных журналов, что и у обычного пользователя без прав администратора, но эта настройка его не блокирует. |
| Пользователь без прав администратора и без разрешений на журналы аудита | Видит личные журналы аудита, только если **Only admin can access logs** отключено. |
| Включено **Settings > Other > Only admin can access logs** | Пользователи без прав администратора и без разрешений на журналы аудита не имеют доступа к журналам аудита. |

К личным журналам относятся записи о подключениях и передаче файлов, где управляемым или управляющим устройством является устройство, назначенное пользователю сейчас, а также записи, где пользователь был управляющим. Для журналов тревог к личным относятся записи об устройствах, назначенных пользователю, или о его учётной записи. Для журналов действий в консоли — записи, где пользователь выполнил действие.

Срок хранения журналов аудита задаётся в **Settings > Other > Log Retention (Days)**. Введите `0`, чтобы хранить все журналы бессрочно. Введите число больше `0`, чтобы автоматически удалять журналы старше указанного числа дней. Очистка выполняется раз в час.

## Экспорт журналов аудита

На панели инструментов каждой страницы журналов есть кнопка **Export as csv**. Экспортированный файл учитывает текущие фильтры на странице и использует то же время, что показано в веб-консоли. За один экспорт выгружается до 1000 записей, но с помощью фильтра **Start Time** можно выгрузить все журналы частями.

Журналы аудита также можно запрашивать с помощью [API-токена](/docs/ru/self-host/rustdesk-server-pro/console/#audits-auditspy) и сценария `audits.py`.
