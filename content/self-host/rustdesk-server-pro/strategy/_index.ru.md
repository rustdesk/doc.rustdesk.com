Стратегии позволяют сразу изменить политики и настройки безопасности клиентов на множестве устройств RustDesk.

Стратегия — это инструмент, с помощью которого администраторы RustDesk массово меняют параметры безопасности на страницах настроек клиентов. Администраторы могут создавать разные стратегии и применять их к разным устройствам.

## Что такое стратегия в RustDesk Server Pro?

Стратегия — это уровень массовых политик для настроек клиентов в RustDesk Server Pro. Используйте её, когда нужно привести настройки безопасности или поведения к единому виду на множестве устройств или у множества пользователей, не меняя каждый клиент вручную.

## Коротко о стратегиях

- Стратегии нужны для массового управления настройками клиентов
- В каждый момент устройством управляет только одна действующая стратегия
- Стратегия устройства имеет наивысший приоритет
- Стратегия пользователя переопределяет стратегию группы устройств
- Если стратегия отключена, назначенные ей устройства больше ею не управляются

## Какое назначение стратегии имеет приоритет?

| Тип стратегии | Приоритет |
| --- | --- |
| Стратегия устройства | Наивысший |
| Стратегия пользователя | Средний |
| Стратегия группы устройств | Наименьший |

## Создание стратегий

Новую стратегию можно создать кнопкой `+`, а действия с ней выполняются через меню, которое появляется при наведении на стратегию.

Во всплывающем меню можно включить (`Enable`) или отключить (`Disable`) стратегию, переименовать (`Rename`), продублировать (`Duplicate`) или удалить (`Delete`) её. Кроме того, можно нажать `Edit Devices`, чтобы изменить устройства, к которым применяется стратегия, или `Edit Users`, чтобы изменить пользователей, к которым она применяется.

Справа от меню стратегии показано число устройств, к которым стратегия фактически применяется с учётом приоритетов.

## Стратегия устройства, стратегия пользователя и стратегия группы устройств

Стратегии применяются в следующем порядке приоритета:
1. Стратегия устройства (наивысший приоритет)
2. Стратегия пользователя
3. Стратегия группы устройств (наименьший приоритет)

Каждым устройством в каждый момент управляет только одна стратегия. Система приоритетов работает так:
- Стратегии устройств имеют приоритет и над стратегиями пользователей, и над стратегиями групп устройств
- Стратегии пользователей имеют приоритет над стратегиями групп устройств
- Стратегии групп устройств применяются ко всем устройствам группы, которым не назначена стратегия устройства или стратегия пользователя


## Изменение устройств

При выборе пункта меню `Edit Devices` откроется диалог со всеми устройствами. Измените состояние флажков и нажмите `Save`, чтобы применить изменения устройств на текущей странице. Чтобы изменить устройства на других страницах, перейдите на них. Для фильтрации устройств можно использовать раскрывающееся меню в правом верхнем углу.

Формат столбца стратегии: стратегия устройства/стратегия пользователя/стратегия группы устройств, или «-» для стратегии по умолчанию.

## Синхронизация стратегий

Каждым устройством может управлять только одна стратегия; если она отключена, устройством не управляет ни одна стратегия. При синхронизации RustDesk запоминает метки времени локальной и серверной стратегии, чтобы определить, нужна ли синхронизация. То есть после завершения синхронизации:

* Если пользователь изменит какие-то параметры, клиент будет использовать параметры пользователя.
* Если администратор изменит содержимое стратегии, параметры клиента будут синхронизированы.
* Если администратор изменит стратегию, к которой относится устройство, параметры клиента будут синхронизированы.

## Изменение стратегий

Внизу стратегии нажмите `Edit`, внесите изменения и нажмите `Submit`. Стратегия будет синхронизирована на устройства в течение 30 секунд.
