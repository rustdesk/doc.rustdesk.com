## Как лучше всего настроить клиенты RustDesk для собственного сервера?

Лучший способ зависит от того, сколькими устройствами вы управляете и используете ли RustDesk Server Pro. Для развёртываний на Pro обычно лучше всего подходит генератор собственного клиента: он заранее прописывает настройки сервера и оформление. Для небольших развёртываний и OSS обычно быстрее ручная настройка, импорт и экспорт или развёртывание сценариями.

## Какой способ настройки клиентов выбрать?

| Способ | Кому подходит | Зачем его использовать |
| --- | --- | --- |
| Генератор собственного клиента | Командам на RustDesk Server Pro | Создаёт заранее настроенные клиенты с параметрами вашего сервера, оформлением и подписью |
| Ручная настройка | Для тестирования и небольших развёртываний | Самый быстрый способ подключить несколько клиентов к собственному серверу |
| Импорт или экспорт | Чтобы повторить проверенную настройку | Копирует одни и те же настройки сервера с одного клиента на другой |
| Сценарии развёртывания | RMM, Intune или массовое развёртывание | Автоматически устанавливает RustDesk и применяет настройки в больших масштабах |
| Параметр командной строки `--config` | Управляемые установки и автоматизация | Применяет строку конфигурации без участия пользователя во время установки сценарием |

## Какие значения нужны большинству клиентов?

Большинству клиентов RustDesk с собственным сервером нужно всего несколько значений:

- `Сервер ID`: обязательно, обычно это имя хоста или IP-адрес вашего `hbbs`
- `Ключ`: обязательно для зашифрованных соединений с вашим собственным сервером
- `Сервер API`: нужен для входа в аккаунт Pro и функций веб-консоли
- `Ретранслятор`: часто необязательно, потому что RustDesk может определить его сам, если вы не хотите указать его явно

## 1. Генератор собственного клиента (только Pro, тариф Basic или Custom)

Можно задать собственное название, логотип, значок, конфигурацию, подписать приложение и многое другое.

Сейчас поддерживаются Windows X64, Mac Arm64 / X64, [Linux](https://twitter.com/rustdesk/status/1788905463678951787) и Android Arm 64.

## 2. Ручная настройка {#2-manual-config}

На главном экране клиента RustDesk нажмите кнопку меню [ &#8942; ] рядом с вашим ID, затем «Сеть». Разблокируйте настройки с повышенными правами и укажите `ID`, `Ретранслятор`, `API` и `Ключ`. Обратите внимание: этот `Ключ` — открытый ключ для шифрования соединения, а не лицензионный ключ, который вы получаете при покупке версии Pro.

![](/docs/en/self-host/client-configuration/images/network-config.png)

Введите имя хоста или IP-адрес `hbbs` в поле **Сервер ID** (на локальной и на удалённой стороне). Два других адреса можно оставить пустыми: RustDesk определит их автоматически (если они не заданы специально). Ретранслятор — это `hbbr` (порт 21117).

Например:

```nolang
hbbs.example.com
```

или

```nolang
hbbs.example.com:21116
```

### Указание `Ключа`

Чтобы установить зашифрованное соединение с собственным сервером, нужно ввести его открытый ключ. Обычно ключ создаётся при первом запуске `hbbs`, его можно найти в файле `id_ed25519.pub` в рабочей папке / папке с данными.

Пользователи `Pro` также могут посмотреть `Ключ` в [веб-консоли](https://rustdesk.com/docs/ru/self-host/rustdesk-server-pro/console/).

![](/docs/en/self-host/rustdesk-server-pro/console/images/console-home.png?v2)

### Указание `Сервера API`

Это нужно только пользователям `Pro`. Если вы можете войти в веб-консоль, но не можете войти в клиенте RustDesk, скорее всего, `Сервер API` указан неправильно.

Если ваш сервер API работает не на порту по умолчанию `21114` (если вы перешли с версии с открытым исходным кодом, этот порт может быть не открыт в брандмауэре), укажите `Сервер API` явно.
Например, если сервер API работает на стандартном порту HTTPS, укажите `Сервер API` как `https://hbbs.example.com`.

Если вы всё ещё не уверены, какое значение указать в `Сервер API`, откройте приветственную страницу веб-консоли: `Сервер API` показан на рисунке выше (поле с подписью `API:`).

## 3. Настройка с помощью импорта или экспорта

1. Настройте клиент RustDesk на одном устройстве, как описано [выше](https://rustdesk.com/docs/ru/self-host/client-configuration/#manual-config).
2. На этом компьютере откройте «Настройки» → «Сеть» и разблокируйте настройки.
3. Нажмите `Экспортировать конфигурацию сервера`.
4. Вставьте скопированную строку в Блокнот или похожую программу.
5. На новом клиенте скопируйте эту строку в буфер обмена.
6. В клиенте RustDesk откройте «Настройки» → «Сеть», разблокируйте настройки и нажмите `Импортировать конфигурацию сервера`.
7. Настройки вставятся автоматически.
8. Нажмите `Применить`.

## 6. Параметр командной строки `--config`
`rustdesk.exe --config <config-string>`

Строку конфигурации можно получить в веб-консоли (она видна на рисунке выше) или в клиенте RustDesk в разделе «Настройки → Сеть» ([здесь](https://github.com/rustdesk/rustdesk/discussions/7118) есть обсуждение этого).
