RustDesk — полнофункциональная альтернатива для удалённого управления с открытым исходным кодом, которую можно развернуть на собственном сервере с минимальной настройкой. Вы полностью контролируете свои данные и можете не беспокоиться о безопасности. Клиент распространяется с открытым исходным кодом, а из серверов можно выбрать полнофункциональный **Professional Server**, который продаётся на нашем [сайте](https://rustdesk.com), или базовый бесплатный сервер с открытым исходным кодом, созданный на основе **Professional Server**.

## Какой вариант RustDesk вам подходит?

| Задача | С чего начать |
| --- | --- |
| Пользоваться RustDesk как пользователь или администратор | [Клиент](/docs/ru/client/) |
| Развернуть бесплатный сервер с открытым исходным кодом | [RustDesk Server OSS](/docs/ru/self-host/rustdesk-server-oss/) |
| Развернуть сервер с веб-консолью, SSO и корпоративными функциями управления | [RustDesk Server Pro](/docs/ru/self-host/rustdesk-server-pro/) |
| Собрать RustDesk из исходного кода или подготовить свой пакет | [Разработка](/docs/ru/dev/) |

## Возможности
- Работает на Windows, macOS, Linux, iOS, Android и в браузере.
- Поддерживает программные кодеки VP8 / VP9 / AV1 и аппаратные кодеки H264 / H265.
- Ваши данные принадлежат вам: собственный сервер легко развернуть в своей инфраструктуре.
- P2P-соединение со сквозным шифрованием на основе NaCl.
- В Windows не нужны права администратора и установка; при необходимости права можно повысить локально или удалённо.
- Мы стараемся делать всё просто и, где можно, ещё проще.
