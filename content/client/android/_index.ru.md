## Передача файлов (Android)

> Требуется RustDesk ≥ 1.1.9

Выберите устройство в списке на главной странице.

Нажмите и удерживайте устройство или нажмите на меню справа и выберите `Передать файлы`.

| Главная | Подключение установлено |
| --- | --- |
| ![](/docs/en/client/android/images/connection_home_file_en.jpg?width=300px) | ![](/docs/en/client/android/images/file_connection_en.jpg?width=300px) |

- Начальная папка — домашняя папка устройства. Чтобы быстро вернуться в неё, нажмите <i class="fas fa-home"></i>.
- Под заголовком показан путь по уровням папок: нажмите на нужную папку, чтобы быстро перейти в неё.
- Нажмите <i class="fas fa-arrow-up"></i>, чтобы перейти в родительскую папку.
- Внизу списка показаны текущий абсолютный путь и число элементов.
- Нажмите `Локальный` / `Удалённый` в заголовке, чтобы переключить страницу.

### Как передавать файлы?

1. **Нажмите и удерживайте** файл или папку в списке, чтобы перейти в **режим множественного выбора** и выбрать несколько элементов.
2. Выбрав файлы, переключитесь на страницу `Локальный` / `Удалённый`. После переключения внизу экрана появится подсказка `Вставить сюда?`.
3. Нажмите на значок вставки, как на рисунке, чтобы передать выбранные элементы в целевую папку.

| --- | --- |

## Настройка сервера ID и ретранслятора

1. Нажмите `Настройки` на нижней панели навигации.
2. Нажмите `ID/Ретранслятор`.
3. Введите имя хоста или IP-адрес вашего сервера ID в поле `Сервер ID`. Поля `Ретранслятор` и `Сервер API` оставьте пустыми, а в поле `Ключ` введите ваш открытый ключ (необязательно, нужен для шифрования). Нажмите **OK**, чтобы сохранить настройки. Клиент автоматически переключится на указанный сервер.

Настроить клиент можно и сканированием QR-кода. Чтобы сгенерировать QR-код, используйте следующий формат (замените значения `host` и `key` на свои):

```nolang
config={"host": "xxx", "key": "xxx"}
```

Затем откройте [онлайн-генератор QR-кодов](https://www.qr-code-generator.com/) и вставьте в него текст выше.

## Демонстрация экрана и файлов Android-телефона

Начиная с версии 1.1.9 клиент для Android умеет предоставлять доступ к экрану и файловой системе телефона.

- Для демонстрации экрана нужен Android 6 или новее
- Для передачи внутреннего звука системы телефона нужен Android 10 или новее
- iOS пока не поддерживает демонстрацию экрана

### Запрос разрешений и запуск службы

Нажмите `Демонстрация экрана` на нижней панели навигации.

Настройте нужные разрешения. При каждом запуске RustDesk разрешения «Захват экрана» и «Управление вводом» нужно запрашивать заново.

![](/docs/en/client/android/images/server_off_en.jpg?width=300px)

| Разрешение | Описание |
| --- | --- |
| Захват экрана | Разрешает доступ к захвату экрана; служба мониторинга включается одновременно с запуском |
| Управление вводом* | Разрешает управляющему устройству управлять вводом на телефоне, например имитировать касания экрана с помощью мыши |
| Передача файлов* | Разрешает передачу файлов; после включения можно удалённо работать с файловой системой этого телефона |
| Захват аудио | Разрешает передавать звук системы телефона (не вход микрофона) |

{{% notice note %}}
Звёздочкой (*) отмечены специальные разрешения. Чтобы их получить, нужно перейти на страницу системных настроек Android и выдать их вручную. Подробности ниже.
{{% /notice %}}

### Запуск службы

После получения разрешения `Захват экрана` служба запускается автоматически. Её также можно запустить кнопкой `Запустить службу`. После запуска служба принимает запросы на управление рабочим столом от других устройств.

Если включено разрешение `Передача файлов`, служба принимает и запросы на работу с файлами от других устройств.

После запуска службы устройство автоматически получает уникальный ID и случайный пароль. Другие устройства могут управлять телефоном по ID и паролю, либо вы можете вручную подтверждать каждый новый запрос.

| До запуска службы | После запуска службы |
| --- | --- |
| ![](/docs/en/client/android/images/server_off_en.jpg?width=300px) | ![](/docs/en/client/android/images/server_on_en.jpg?width=300px) |

{{% notice note %}}
1. Нажатие `Запустить службу` по умолчанию включает разрешение `Захват экрана`.
2. Пока разрешение `Захват экрана` не получено, другие устройства не могут отправлять запросы на управление.
3. Изменение любых разрешений, кроме `Захват экрана`, влияет только на новые подключения и не затрагивает уже установленные. Чтобы изменить разрешения для установленного подключения, сначала закройте его, измените разрешения и затем примите запрос на управление снова.
{{% /notice %}}
