## クイックアンサー

ポータブル版 RustDesk クライアントを使っていても、特定作業や被操作側で管理者権限が必要なら portable elevation を使います。完全版クライアントを入れないが、高権限の遠隔サポートは必要な場合に役立ちます。

## 重要なポイント

- 起動時に昇格が必要か、セッション中だけでよいかを決めます
- 被操作側と操作側の両方で昇格プロンプトを確認します
- 展開前にサポート担当へ昇格フローを説明します

<!-- GEO-LOCALIZED-INTRO:END -->

Windowsポータブルプログラムには管理者権限がないため、以下の問題が発生する可能性があります：

- UAC（ユーザーアカウント制御）ウィンドウがポップアップしたときに画面を送信できない。
- タスクマネージャーなどの昇格されたウィンドウがポップアップしたときに、マウスが反応しなくなる。

権限を昇格することで、RustDeskは起動時またはセッション中に管理者権限を持つプロセスを作成でき、スクリーンショットとマウス操作を実行できるようになり、上記の問題を回避できます。

## 起動時に昇格

この方法では、リモートユーザーは接続時に昇格を要求する必要がありません。2つの方法があります：

* 方法1：ポータブルプログラムの名前を `-qs-` または `-qs.exe` または `_qs.exe` を含むように変更します（>= 1.4.6）、または `qs.exe` で終わるようにします（1.2.0 ~ 1.4.5）。左マウスボタンをクリックして実行し、UACウィンドウで `受け入れる` をクリックします。

* 方法2：右クリックして管理者として実行します。

## 制御される側で昇格

制御される側は、接続時に直接 `受け入れて昇格` をクリックするか、既に接続されている場合は `昇格` をクリックできます。

## 制御側で昇格を要求

操作する側のアクションメニューから `昇格を要求` を選択します。リモートユーザーに管理者権限がある場合は `リモートユーザーに認証を求める` を選択します。リモートユーザーが Windows の標準アカウントを使用している場合は `管理者のユーザー名とパスワードを送信` を選択し、操作する側で管理者の資格情報を入力します。接続直後、アプリを管理者として起動する前に要求できます。**どちらの方法でも、リモートコンピューターの前にいる人が RustDesk の UAC プロンプトに応答する必要があります。**

### アプリと RustDesk の UAC プロンプト

アプリを管理者として起動するときと、RustDesk の権限を昇格するときには、それぞれ UAC プロンプトが表示されます。RustDesk の昇格を要求した時点でアプリのプロンプトが開いている場合は、リモートユーザーにそちらを先に操作してもらいます。

1. **アプリのプロンプト**（例：Windows コマンド プロセッサ）では、**はい**をクリックすると管理者として起動し、**いいえ**をクリックすると起動を取り消します。
2. **`rustdesk.exe` のプロンプト**では、**はい**をクリックして RustDesk の権限を昇格します。Windows から管理者の資格情報を求められた場合は、先に入力します。

昇格後は、操作する側から UAC プロンプトに応答したり、管理者権限が必要なボタンをクリックしたりできます。リモートユーザーがアプリの起動を取り消した場合は、ここで改めて管理者として起動できます。

### RustDesk の UAC プロンプトで再び資格情報を求められる場合

RustDesk は送信された資格情報を使い、管理者アカウントで補助プロセスを起動します。このプロセスが昇格を要求すると、Windows は**ユーザー アカウント制御: 管理者承認モードでの管理者に対する昇格時のプロンプトの動作**ポリシーを適用します。グループ ポリシーの**コンピューターの構成 → ポリシー → Windows の設定 → セキュリティの設定 → ローカル ポリシー → セキュリティ オプション**にあります。

**セキュリティで保護されたデスクトップで資格情報を要求する**に設定されていると、操作する側から資格情報を送信済みでも、リモートコンピューターで `rustdesk.exe` の UAC プロンプトに管理者の資格情報を入力する必要があります。他のアプリを開く前に昇格を要求した場合も同様です。[Microsoft の UAC ポリシーに関するドキュメント](https://learn.microsoft.com/ja-jp/windows/security/application-security/application-control/user-account-control/settings-and-configuration)

| シナリオ | 方法 |
| :---: | :---: |
| 昇格が不要 | プログラムをインストール |
| 制御される側にユーザーが利用できない | リネーム<br/>*または*<br/> 管理者として実行 |
| 制御される側にユーザーが利用可能<br/>*かつ*<br/> 接続時に即座に昇格<br/>*かつ*<br/> 受け入れクリック接続 | 制御される側で接続を受信するときに `受け入れて昇格` をクリック |
| 制御される側にユーザーが利用可能<br/>*かつ*<br/> 必要に応じて昇格 | 制御される側の接続管理ウィンドウで `昇格` をクリック<br/>*または*<br/> 制御側で昇格を要求 |
