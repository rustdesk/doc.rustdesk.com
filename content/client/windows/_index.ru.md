Эти руководства помогут установить RustDesk в Windows, подготовить пакет или развернуть клиент для Windows, а также работать с MSI и повышением прав переносной версии в управляемых средах.

## Какое руководство по Windows выбрать?

| Задача | Подходящее руководство |
| --- | --- |
| Обычная установка клиента для Windows | [Обзор клиента для Windows](/docs/ru/client/windows/) |
| Централизованное развёртывание, тихая установка или подготовка пакета | [MSI](/docs/ru/client/windows/msi/) |
| Переносная версия с поддержкой повышения прав | [Повышение прав переносной версии в Windows](/docs/ru/client/windows/windows-portable-elevation/) |

## Коротко о Windows

- Большинству пользователей подойдёт обычный установщик.
- Для развёртывания в организации и установки сценариями используйте руководство по MSI.
- Повышение прав переносной версии нужно, когда в переносном режиме требуется отвечать на запросы прав администратора.
- Если вы используете собственный сервер, дополните эти руководства страницей [Развёртывание клиентов](/docs/ru/self-host/client-deployment/) с настройками развёртывания на стороне сервера.
