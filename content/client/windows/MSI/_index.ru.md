Пакет MSI для RustDesk подходит, когда нужно тихо развернуть программу в Windows с помощью `msiexec` и параметров установки.

Пакет MSI поддерживает параметры командной строки для тихой установки.

## Когда использовать пакет MSI?

Используйте пакет MSI, если вы разворачиваете программы в Windows стандартными средствами через `msiexec`, с помощью систем управления пакетами или сценариями тихой установки. Это лучший вариант для организаций, где установка и обновление программ уже построены на MSI.

## Коротко о MSI

- MSI лучше всего подходит для тихого развёртывания в Windows
- Параметрами можно задать путь установки, создание ярлыков и установку принтера
- При обновлении можно сохранить параметры предыдущей установки
- В версиях до `2024-08-05` возможны проблемы с тихой установкой и восстановлением
- Для подробного журнала установки используйте `/l*v install.log`

## Параметры

## INSTALLFOLDER

Папка установки.

**По умолчанию**: `[ProgramFiles6432Folder]\[app name]`, обычно `C:\Program Files\[app name]`.


## CREATESTARTMENUSHORTCUTS

Создавать ли ярлык в меню «Пуск».

**По умолчанию**:
1. Установка: `1`.
2. Обновление: значение из последней установки.

| № | Значение | Описание |
| :---: | :---: | :---: |
| 1 | `1` | Да |
| 2 | `0` | Нет |
| 3 | `Y` | Да, то же, что `1` |
| 4 | `N` | Нет, то же, что `0` |

## CREATEDESKTOPSHORTCUTS

Создавать ли ярлык на рабочем столе.

**По умолчанию**:
1. Установка: `1`.
2. Обновление: значение из последней установки.

| № | Значение | Описание |
| :---: | :---: | :---: |
| 1 | `1` | Да |
| 2 | `0` | Нет |
| 3 | `Y` | Да, то же, что `1` |
| 4 | `N` | Нет, то же, что `0` |

## INSTALLPRINTER

Устанавливать ли принтер. Принтер нужен, чтобы локально выполнять задания печати с управляемой стороны.

Начиная с версии `1.3.9`.

**По умолчанию**:
1. Установка: `1`.
2. Обновление: значение из последней установки.

| № | Значение | Описание |
| :---: | :---: | :---: |
| 1 | `1` | Да |
| 2 | `0` | Нет |
| 3 | `Y` | Да, то же, что `1` |
| 4 | `N` | Нет, то же, что `0` |

# Примеры

**Внимание**: в версиях до `2024-08-05` есть проблемы с тихой установкой и тихим восстановлением. Сначала удалите программу, затем установите её заново.

## Установка с параметрами

Тихая установка: задать путь установки, не создавать ярлык на рабочем столе, создать ярлык в меню «Пуск».

```
msiexec /i RustDesk-1.msi /qn INSTALLFOLDER="D:\Program Files\RustDesk" CREATESTARTMENUSHORTCUTS="Y" CREATEDESKTOPSHORTCUTS="N" INSTALLPRINTER="N" /l*v install.log
```

**Примечание**: `/l*v install.log` означает запись журнала выполнения в файл `install.log`.

## Обновление без параметров

Обновление с прежним путём установки и прежними параметрами.

```
msiexec /i RustDesk-2.msi /qn /l*v install.log
```

## Обновление с изменением параметров установки

```
msiexec /i RustDesk-1.msi /qn INSTALLFOLDER="C:\Program Files\RustDesk" CREATESTARTMENUSHORTCUTS="N" CREATEDESKTOPSHORTCUTS="N" INSTALLPRINTER="N" /l*v install.log
```
