Bu Windows kılavuzlarını kullanarak RustDesk'i kurabilir, Windows istemcisini paketleyebilir veya dağıtabilir ve yönetilen ortamlarda MSI veya taşınabilir ayrıcalık yükseltme iş akışlarını yönetebilirsiniz.

## Hangi Windows kılavuzunu seçmelisiniz?

| İhtiyaç | En İyi Kılavuz |
| --- | --- |
| Standart Windows istemci kurulumu | [Windows istemci genel bakış](/docs/tr/client/windows/) |
| Yönetilen dağıtım, sessiz kurulum veya paketleme | [MSI](/docs/tr/client/windows/msi/) |
| Ayrıcalık yükseltme desteğine sahip taşınabilir mod | [Windows Taşınabilir Ayrıcalık Yükseltme](/docs/tr/client/windows/windows-portable-elevation/) |

## Windows hızlı yanıtlar

- Çoğu son kullanıcı için standart yükleyiciyi kullanın.
- Kurumsal dağıtım ve komut dosyasıyla yükleme için MSI kılavuzunu kullanın.
- Taşınabilir modda yönetici istemlerine ihtiyaç duyduğunuzda taşınabilir ayrıcalık yükseltmeyi kullanın.
- Kendi sunucunuzu barındırıyorsanız, sunucu tarafı dağıtım ayarları için bu kılavuzları [İstemci Dağıtımı](/docs/tr/self-host/client-deployment/) ile birleştirin.
