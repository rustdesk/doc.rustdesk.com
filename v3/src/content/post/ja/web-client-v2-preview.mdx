2024年10月、私たちは **RustDesk Web クライアント V2 プレビュー** を公開しました。より強力なデコード性能、海外のキーボード配列へのより良い対応、テキストだけでなく画像にも対応したクリップボード、そしてファイル転送を備えています。ブラウザーが課す制約の範囲内で、Web 版の機能とユーザー体験をデスクトップクライアントにそろえるよう取り組みました。

RustDesk Web クライアント V2 プレビューは、https://rustdesk.com/web にアクセスして利用できます。V2 から自社のサーバーに接続したい場合は、[ドキュメント](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/faq/)に従って WebSocket Secure（WSS）への対応を設定し、ポート 21118/21119 の ID サーバーとリレーサーバーの WebSocket バックエンドを HTTPS/WSS 経由でプロキシしてください。リバースプロキシで TCP 443 を公開する場合、これらのバックエンドのポートは内部にとどめておきます。

```nginx
    location /ws/id {
        proxy_pass http://localhost:21118;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws/relay {
        proxy_pass http://localhost:21119;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
```

Web クライアントは **RustDesk Server Pro にも統合されている** ため、公開版に頼らず、`https://rustdesk.yourcompany.com/web` のように自社のサーバーから配信できます。

## 自社のサーバーで Web クライアントを使う 2 つの方法

- **公開 Web クライアント（`rustdesk.com/web`）を自社のサーバーに接続する。** RustDesk がホストする Web クライアントを使い、自社の ID/リレーサーバーに接続できますが、設定はご自身で行います。ブラウザーが自社のサーバーに到達するには、WebSocket Secure（WSS）と適切な CORS ヘッダーが必要です。詳しくは[Web クライアント向けの WSS と CORS の設定](https://github.com/rustdesk/rustdesk/wiki/FAQ#wss-and-cors-setup-for-web-client)をご覧ください。
- **セルフホストの Web クライアント（Server Pro が `https://your-server/web` で配信）。** Web クライアントは[RustDesk Server Pro に統合されている](https://github.com/rustdesk/rustdesk/wiki/FAQ#is-web-client-integrated-into-rusetdesk-server-pro)ため、公開版ではなく自社のサーバーから動作します。Web クライアントのセルフホストは**エントリーレベルのプランには含まれておらず**、**（ユーザー数 × 10）＋ デバイス数 ≥ 400** を満たす規模のプランが必要です（例：ユーザー 10 名／デバイス 300 台、ユーザー 30 名／デバイス 100 台、ユーザー 20 名／デバイス 200 台）。セルフホストの Web クライアントは[カスタマイズ](https://github.com/rustdesk/rustdesk/wiki/FAQ#how-to-customize-self-hosted-web-client)することもできます。

どちらの方法でも、Web クライアントは**コントローラー**です。ブラウザーのタブからほかのデバイスを操作できますが、ブラウザーのタブを無人アクセスのホストにすることはできません。

今すぐ [Web クライアント](https://rustdesk.com/web)をお試しください。現在の展開方法の詳細は [Server Pro のドキュメント](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/)をご覧ください。クリップボードの権限やキーボードの扱いはブラウザーによって異なるため、チームで使うブラウザーでテストしてください。
