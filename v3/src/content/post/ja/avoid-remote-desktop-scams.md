リモートデスクトップ詐欺とは、犯罪者が正規のリモートアクセスソフトウェアをインストールするよう誘導し、それを使ってパソコンを乗っ取り、銀行口座からお金を抜き取ったり、データを盗んだり、マルウェアを仕込んだりする詐欺です。使われるツール自体は、IT部門が日常的に使っているものとまったく同じです。それを詐欺にするのは、相手が誰で、どうやって入り込んできたかです。

このガイドは、あえて特定のベンダーに偏らない内容にしています。RustDeskを含め、どのリモートデスクトップ製品もこのように悪用される可能性があります。目的は、手口を見分けて断れるようになること、そしてすでに被害に遭ってしまった場合に立て直せるようにすることです。

## リモートアクセス詐欺の手口

[米国連邦取引委員会（FTC）](https://consumer.ftc.gov/articles/how-spot-avoid-and-report-tech-support-scams)と[FBI](https://www.fbi.gov/how-we-can-help-you/scams-and-safety/common-frauds-and-scams/tech-support-scams)は、どちらも驚くほど一貫した手口を説明しています。

1. **誘い文句。** 「パソコンがウイルスに感染しています」と警告するポップアップが表示されたり、予期しない電話、メール、SMSが届いたりします。送り主は、Microsoft、Apple、Amazon、取引先の銀行、公共料金の会社、あるいは自社のIT部門など、信頼できる相手になりすまします。
2. **作り出された緊急性。** 「アカウントが乗っ取られた」「ウイルスが広がっている」「返金が待っている」「サービスが停止される」といった話を持ちかけられます。FTCによれば、詐欺師は「考える時間を与えずに行動させたい」と考えており、急がせること自体が狙いです。
3. **ツールのインストール。** 問題を「解決する」ためと言って、「無料のリモートサポートソフト」をダウンロードするよう求めてきます。実在する本物のソフトウェアなので、かえって信じてしまいます。
4. **アクセスの許可。** 画面に表示された接続コードやパスワードを読み上げるよう、あるいは着信したセッションを承認するよう指示されます。通常、デバイスIDだけで操作できるわけではありません。コードを伝えるか、接続要求を承認した瞬間に、相手が入り込みます。
5. **操作の乗っ取り。** 偽のウイルススキャンを見せたり、銀行のサイトを開いたり、送金したり、新しい口座を開設したりします。[FBIボストン支局](https://www.fbi.gov/contact-us/field-offices/boston/news/press-releases/fbi-warns-public-to-beware-of-tech-support-scammers-targeting-financial-accounts-using-remote-desktop-software)は、詐欺師がこのアクセスを悪用して仮想通貨の口座を開設し、被害者の実際の銀行預金を引き出していると警告しています。

被害は決して机上の話ではありません。同じFBIの警告では、メイン州のある夫婦の事例が紹介されています。ポップアップに表示された「Fidelity」の番号に電話をかけたところ、リモートデスクトップソフトウェアをインストールして、偽の「Microsoft」と「Fidelity」の担当者に口座を見せるよう指示され、約**110万ドル**を失いました。

## 見分けるべき危険信号

リモートアクセス詐欺のほとんどは、次のいずれかに当てはまります。

- **一方的な連絡。** 報告した覚えのないパソコンの問題を「直してあげる」と、見知らぬ相手から連絡が来ます。FTCはこの点をはっきり述べています。FTCとその返金業務の委託先は「ギフトカードでの支払いを求めることは決してなく」、「デバイスへのリモートアクセスを求めることもない」としています。Microsoft、Apple、銀行も同じです。
- **電話番号が表示されたポップアップ。** 正規のセキュリティ警告が、サポート窓口への電話を促すことはありません。その番号は詐欺師のものです。
- **プレッシャーと緊急性。** 「今すぐやらないとすべてを失う」という言い方は、サポートの手順ではなく心理操作の手口です。
- **ソフトウェアのインストールとコードの読み上げの要求。** これが詐欺の仕組みの核心です。まっとうな用件で突然電話してくる相手に、こんなものは必要ありません。
- **お金の話への転換。** ギフトカード、電信送金、暗号資産、あるいはなぜか多すぎる「返金」があり、その差額を「返送」するよう求められます。
- **ログイン中も電話を切らせない。** 銀行の認証情報を入力する様子を見たいからです。

## 正規のサポートと詐欺の違い

| | 正規のリモートサポート | 詐欺 |
| --- | --- | --- |
| 誰が始めるか | 自分で調べた番号に、自分から連絡する | 相手から突然連絡してくる |
| 問題の内容 | すでに自分が報告した問題 | 相手が「見つけた」と称して伝えてくる問題 |
| 緊急性 | 予定どおり、落ち着いて進む | 「今すぐ対応しないと大変なことになる」 |
| 接続コード | 理解したうえで、自分の判断で伝える | 急いで読み上げるよう圧力をかけられる |
| 支払い | 通常の請求（発生する場合） | ギフトカード、送金、暗号資産、「返金」 |
| 銀行口座へのアクセス | パソコンの修理には不要 | それこそが本当の狙い |

## すでに詐欺師にアクセスを許してしまった場合の対処法

通話中、あるいは後になって詐欺だと気づいたら、次の順番ですぐに行動してください。

1. **インターネットから切断する。** Wi-Fiをオフにするか、LANケーブルを抜いて、相手のセッションをすぐに断ち切ります。
2. **インストールさせられたリモートアクセスアプリを削除する。** 方法がわからなければ、信頼できる地元の技術者に頼みましょう。
3. **マルウェアをスキャンする。** ウイルス対策ソフトでフルスキャンを実行します。重要なマシンが関わっていた場合は、専門業者による駆除も検討してください。何かを仕込まれた可能性があると考えて対応します。
4. **別の信頼できるデバイスからパスワードを変更する。** まずメールと銀行、次に同じパスワードを使い回しているサービスを変更します。
5. **銀行やカード会社に連絡する。** 不正を報告し、送金の取り消しが可能か確認するとともに、身に覚えのない取引がないか注意してください。
6. **個人情報を守る。** 個人情報を伝えてしまった場合は、米国の主要な信用情報機関3社（Equifax、Experian、TransUnion）すべてに、不正利用警告（フロードアラート）またはクレジットフリーズを設定してください。
7. **地域の窓口に通報する。** **米国**では、FTCの[ReportFraud.ftc.gov](https://reportfraud.ftc.gov)と[FBI IC3](https://www.ic3.gov)に届け出てください。米国以外では、地元の警察と該当する詐欺の通報窓口に連絡し、地域で取れる個人情報保護の手段を銀行に相談してください。

## 詐欺を防ぐには

予防は、いくつかの習慣に集約されます。

- **向こうから連絡してきた相手に頼まれても、リモートソフトウェアをインストールしない。** 方向を逆にしましょう。助けが必要なときは、ベンダーの正規の電話番号を自分で調べて、こちらから連絡します。
- **自分から意図して連絡した相手以外には、接続コードを読み上げない。**
- **ポップアップに表示された電話番号は偽物だと考える。** 電話をかけずにブラウザを閉じてください。必要なら強制終了します。
- **一度落ち着く。** 急がせるのは詐欺師の手口です。本物の機関なら、いったん電話を切ってかけ直しても問題ありません。
- **周りに相談する。** こうした詐欺は、高齢者やストレスを抱えた人を特に狙う傾向があります。家族に「これっておかしくない？」と一言聞くだけで、相手の術中から抜け出せます。

## リモートデスクトップツールの位置づけ

繰り返しになりますが、悪いのはソフトウェアではありません。リモートデスクトップツールは、IT部門が世界中のコンピューターを動かし続けるための手段であり、まったく同じアプリが、誰の手にあるかによって命綱にも凶器にもなります。特定の製品を責めても意味はありません。防御の要は、誰を中に入れるかを自分で管理することです。

そのうえで、リモートサポートを業務として*提供する*側であれば、いくつかの構成上の選択でリスクを減らせます。RustDeskのサーバーをセルフホストすれば、ID/ランデブーサーバーとリレーサーバーを自社管理のインフラに置けます。接続できる相手は自社の管理策で決まります。強力で使い回しのない固定パスワードと接続時の2FAで基本的な[無人アクセスの安全対策](/ja/blog/rustdesk-unattended-access-setup-ja)を実践し、被操作デバイスにIPまたはIDの許可リストを追加し、Server Proのユーザー単位・デバイスグループ単位の[アクセス制御](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/permissions/)を使ってください。さらに、RustDeskは[オープンソース](https://github.com/rustdesk/rustdesk)なので、自分やセキュリティチームが、マシン上で何をしているかを正確に監査できます。

それでも、RustDeskを含め、どのツールも詐欺を完全には防げません。だまされてクライアントをインストールし、コードを読み上げてしまえば、どのプラットフォームでも被害に遭う可能性があります。構成上の対策で下げられるリスクはありますが、ここまでのすべての警告の中心にあるシンプルな原則、つまり「*向こうから*連絡してきた相手にパソコンの操作を渡さない」に代わるものではありません。

特定のツールが安全性にどう対応しているか、またどのようになりすましに使われるかを詳しく知りたい方は、関連ガイドの[AnyDeskは安全か](/ja/blog/is-anydesk-safe-ja)と[Chrome Remote Desktopは安全か](/ja/blog/is-chrome-remote-desktop-safe-ja)もご覧ください。
