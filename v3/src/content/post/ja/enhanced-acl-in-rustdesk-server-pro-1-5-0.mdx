デバイスグループとユーザー単位のアクセス制御を備えた RustDesk Server Pro 1.5.0 をリリースしました。

## 変更履歴

- デバイスグループとそのアクセス制御ルールを追加
- ユーザー単位のアクセス制御を追加
- デバイスグループ向けのポリシーを追加
- 並べ替え可能なテーブルを追加
- メールアドレスが一致する場合、OIDC のサインインを既存のアカウントに関連付けるように変更
- デバイス ID で `-`（ハイフン）を使えるように変更
- OIDC の名前が `null` の場合にサインインに失敗する問題を修正

デバイスグループは RustDesk Server Pro 1.5.0 の新機能です。これまで RustDesk はシンプルさを優先してデバイスグループを導入せず、ACL（アクセス制御リスト）の管理にはユーザーグループだけを使っていました。しかしこの方法では、大規模な組織でのアクセス権限の設定が煩雑になっていました。そこでバージョン 1.5.0 で、デバイスグループとユーザー単位の ACL を導入することにしました。デバイスをグループにまとめ、グループごとにポリシーを適用できるようになり、大規模な環境でのデバイス管理が大きく改善されます。

RustDesk Server Pro は当初ユーザーグループにしか対応していませんでしたが、今回のアップデートでデバイスグループにも対応しました。各デバイスはユーザーに関連付けられるのに加えて、1 つのデバイスグループに割り当てることができます。これにより、特定のデバイスへのアクセスを制限したり許可したりするなど、デバイスグループに基づく追加のポリシーを適用できます。さらにこのリリースでは、ユーザーグループに加えて個々のユーザーに権限を設定できるユーザー単位の ACL も導入され、アクセス管理の柔軟性と制御性が高まりました。

**更新（2026年）：** その後の Server Pro のリリースで、セッション中の権限を管理する[コントロールロール](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/control-role/)が追加されました。ユーザーグループとデバイスグループの権限は累積するため、どちらからでもアクセスを許可できます。現在の設定方法については、[アクセス制御のドキュメント](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/permissions/)をご覧ください。
