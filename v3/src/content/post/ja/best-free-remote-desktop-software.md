## 「無料」の本当の意味とは

「無料 リモートデスクトップソフト」で検索すると、無料をうたうツールがずらりと並びます。ただし、無料なのは無料でなくなるまでの間だけ、ということも少なくありません。TeamViewerとAnyDeskはどちらも無料プランを提供していますが、ライセンス上は個人利用向けで、両社とも商用利用の自動検出でその境界を運用しています。業務で使うには相応の契約が必要で、個人ユーザーでも[TeamViewerで商用利用のフラグが立つ](/ja/blog/teamviewer-commercial-use-detected-ja)ことや、[AnyDeskで同じことが起きる](/ja/blog/anydesk-commercial-use-detected-ja)ことがあります。セッションがタイムアウトし、有料プランへの切り替えを促されるのです。

そこで本ガイドでは、より厳しい基準を設けます。リストに載るのは、**本当に無料で運用できる**ツールで、できれば商用利用の「地雷」なしに**ビジネス**でも無料で使えるものです。これで個人利用限定のプランは除外され、実際にワークフローを組めるツールだけが残ります。

対象範囲について補足します。本記事はあくまで*無料*という観点からの比較で、判断基準は価格と利用条件であり、コードを検査できるかどうかではありません。監査可能性やライセンスは関連しつつも別の問題です。重なる部分はありますが、「無料」と「オープンソース」は同じではありません。

## 本当に無料な選択肢

以下では、ビジネスでも本当に無料で使えるツールから順に、セルフホスティング、クロスプラットフォーム対応、運用負荷を考慮して並べています。

### RustDesk — オープンソースのクライアントと、無料でセルフホストできるServer OSS

最初にRustDeskを挙げるのは、クライアントとRustDesk Server OSS（無料のコミュニティサーバー）が<strong>[AGPLライセンス](https://github.com/rustdesk/rustdesk)</strong>で、**Server OSSにはライセンス料も有効期限も商用利用の判定もない**からです。クロスプラットフォーム（Windows、macOS、Linux、Android、iOS）に対応し、Windows、macOS、Linuxのホストではファイル転送と固定パスワードによる無人アクセスが使えます。Androidは有人セッションのホストになれ、iOSアプリは操作側（コントローラー）専用です。ソースコードは誰でも検査し、独自にビルドできます。

**注意点：** サーバーは自分で運用します。ハードウェア要件は控えめですが、リレーの帯域を見積もり、パッチを当て、監視し、バックアップを取る必要があります。有料でプロプライエタリなServer Proは、Webコンソール、アクセス制御、デバイスグループなどの管理機能を追加し、カスタムクライアントの生成はBasicプランから利用できます。[最新のプラン](https://rustdesk.com/pricing)をご覧ください。

### Chrome Remote Desktop — 無料でシンプル、接続の調整はGoogleが管理

Googleの[Chrome Remote Desktop](https://support.google.com/chrome/answer/1649523)は無料のブラウザベースのツールで、リモートアクセスとしてはこれ以上ないほど手軽です。Googleは、組織での利用を有効化、無効化、制限するための[企業向け管理ポリシー](https://support.google.com/chrome/a/answer/2799701)も文書化しています。

**注意点：** GoogleのIDとGoogleが運用するシグナリングサービスが必須で、ドラッグ＆ドロップでのファイル転送、リモート印刷、RustDeskのようなデバイスグループなど、サポートチームに便利な機能の一部がありません。Googleは組織単位のポリシーを文書化していますが、セルフホスト型の制御プレーンはありません。セッションの確立はGoogleを介して調整され、実際の通信は直接またはSTUN経由の経路を使い、必要な場合はTURN／Googleのリレーを使います。詳しくは[Chrome Remote Desktopの代替](/ja/blog/chrome-remote-desktop-alternative-ja)のガイドで解説しています。

### VNCファミリー — 無料のオープンなプロトコル

VNCは、長い歴史を持つリモートアクセス実装のファミリーです。[TigerVNC](https://tigervnc.org/)、[TightVNC](https://www.tightvnc.com/)、[UltraVNC](https://uvnc.com/)などの無料の実装を使えば、ライセンス費用なしで別のマシンの画面を操作でき、プロトコル自体も本当にオープンです。

**注意点：** 素のVNCは画面表示のプロトコルで、NATトラバーサルやリレーの機能を内蔵していません。そのため、インターネット越しにマシンへ接続するには、たいてい自分で**ポート転送かVPN**を用意し、さらに暗号化とアクセス制御も設定する必要があります。強力で無料ですが、周辺のインフラは自分で組み立てることになります。（トレードオフについては[RustDesk vs VNC](/ja/blog/rustdesk-vs-vnc-ja)の比較をご覧ください。）

### Apache Guacamole — 無料のクライアントレスHTML5ゲートウェイ

[Apache Guacamole](https://guacamole.apache.org/)は、Apache 2.0ライセンスの「クライアントレスなリモートデスクトップゲートウェイ」です。HTML5ベースなので、「サーバーにGuacamoleをインストールすれば、デスクトップにアクセスするのに必要なのはWebブラウザだけ」で、プラグインもクライアントソフトも要りません。**RDP、VNC、SSH**といった標準プロトコルへの接続を仲介します。

**注意点：** Guacamoleはそれ自体が一つのインフラプロジェクトです。ゲートウェイを立ち上げ、既存のRDP／VNC／SSHのエンドポイントにつなぎ、自分で管理します。すでにそうしたバックエンドがあり、ブラウザからの一元的なアクセスを求める場合に真価を発揮しますが、2分で使える1対1の接続ツールとしてはあまり向いていません。

### MeshCentral — 無料のエージェント型フリート管理

[MeshCentral](https://github.com/Ylianst/MeshCentral)は、無料のオープンソース（Apache 2.0）でセルフホスト型の「フル機能のコンピューター管理Webサイト」です。自分でサーバーを運用し、管理対象デバイスにエージェントをインストールすると、LAN内でもインターネット経由でも、フリート全体に対してWebベースのリモートデスクトップ、ターミナル、ファイル管理が使えます。

**注意点：** エージェント型で管理寄りの設計なので、軽量な1対1の接続ツールよりセットアップに手間がかかり、UIも管理者向けです。無料のフリート管理コンソールが欲しいなら申し分ありませんが、できるだけシンプルな単発の接続が目的なら機能過多です。

### Remmina — 無料のLinux向けクライアント

[Remmina](https://remmina.org/)は、LinuxなどのUnix系システム向けの無料でコピーレフトなリモートデスクトップ**クライアント**で、RDP、VNC、SSH、SPICEなどに1つの統一されたインターフェースで対応しています。

**注意点：** Remminaは*クライアント*であり、完全なリモートアクセスシステムではありません。それらのプロトコルにすでに対応しているサーバーに接続するもので、ホスト側の機能、NATトラバーサル、管理レイヤーは提供しません。Linuxでは定番の無料クライアントなので、サーバー側には別のものを組み合わせてください。

## 無料のビジネス利用にRustDeskが合う場面

無料の選択肢の多くでは、Googleが管理するシンプルさ（CRD）、より重いインフラ（GuacamoleやMeshCentral）、自前のネットワーク構築（VNC）のどれかを選ぶことになります。RustDeskなら、無料で運用するためにビジネス利用、クロスプラットフォーム対応、セルフホスティング、監査可能性のどれかを諦める必要はありません。

- **監査できるオープンソース。** クライアントとServer OSSのコードは[AGPL](https://github.com/rustdesk/rustdesk)です。読んで、ビルドして、検証できます。
- **ライセンス料も有効期限もないServer OSS。** オープンソースライセンスのもとでセルフホストでき、商用利用のフラグもありません。
- **自社で運用するサーバーサービス。** 自社のID/ランデブーサーバーが接続を調整し、自社のリレーがリレー経由の通信を中継します。直接セッションはエンドポイント間を流れます。
- **主要なプラットフォームすべてに対応。** Windows、macOS、Linux、Androidがホストになり、iOSはコントローラーアプリです。

チームがServer OSSでは物足りなくなったら、[Server Pro](https://rustdesk.com/pricing)がコンソールとデバイスグループを、Basicプランからはカスタムクライアントとシングルサインオン（SSO）を追加します。引き続きセルフホスト型で、ログインユーザー数と管理対象デバイス数でライセンスされ、標準プランには無制限の同時接続が含まれます。

## 無料で、本当に自分たちのもの

Server OSSには**ライセンス料も有効期限もなく**、ランデブーとリレーのサービスを自社で運用できます。まずは小規模なパイロットで、接続性、各プラットフォームの権限、必要なワークフローを確認し、そのうえでServer Proの管理機能が必要かどうかを判断してください。

## 無料で始めて、合うなら無料のまま

Server OSSは、無料のまま無料であり続ける珍しいタイプの「無料」です。オープンソースで、有効期限もなく、いつか作動する商用利用のフラグもありません。役に立つ限り使い続けてください。後からチームがProのコンソールやブランド化したクライアントを必要とした場合は、評価条件のご質問は[sales@rustdesk.com](mailto:sales@rustdesk.com)へ、最新の料金は[rustdesk.com/pricing](https://rustdesk.com/pricing)でご確認いただけます。
