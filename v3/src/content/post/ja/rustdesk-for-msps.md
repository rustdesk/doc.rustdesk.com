ほとんどのMSPが求めているのは、新しいリモートサポートツールではありません。ツールを*減らす*ことです。あちらにクラウド型リモートサポートのシート、こちらに技術者単位のツール、単発の作業にはスタンドアロンのクイックサポートユーティリティ。それぞれにコンソール、契約、更新があります。RustDeskは、それらをセルフホスト型でブランド化できる1つのプラットフォームに置き換えます。何かを廃止する前に、技術者が頼りにしているPSA／RMMとの連携とエンドポイントのワークフローをパイロットで確認してください。

このガイドでは、MSPのワークフローに向けて、RustDeskのオープンソースのクライアント、セルフホスト型のサーバーの選択肢、商用のProによる管理機能、ブランディング、ライセンスを説明します。

## リモートアクセスのサービスを自社で運用する

RustDesk Server Proは**セルフホスト型**で、ID/ランデブー、リレー、コンソール、保存される管理データを自社のチームが運用します。RustDeskのクライアントとRustDesk Server OSS（無料のコミュニティサーバー）は<strong>[AGPLライセンス](https://github.com/rustdesk/rustdesk)</strong>で、Server Proは商用のプロプライエタリなセルフホスト型サーバーソフトウェアです。顧客のセキュリティレビューで「このエージェントは当社のエンドポイントで何をしているのか」と問われても、クローズドなバイナリではなくクライアントのソースコードを示せますし、サーバー側のサービスをどこで動かすかも自社で選べます。

MSPが統合によって手放していくツール群と、セルフホスト型の単一のプラットフォームを比べると次のようになります。

|                                    | 個別のクラウド型リモートサポートツール | RustDesk Server Pro                                                                                    |
| ---------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 管理するコンソール                 | ツールごとに1つ                        | セルフホスト型の単一のコンソール                                                                       |
| クライアントのブランディング       | 製品とプランによる                     | Basicプラン以上でカスタムブランドのクライアントジェネレーター                                          |
| ホスティング                       | ベンダーのクラウド                     | セルフホスト（オンプレミスまたは自社のVPS）                                                            |
| ソース                             | 製品によるが、プロプライエタリが一般的 | 監査できるAGPLのクライアント                                                                           |
| ライセンスされる同時接続／チャネル | プランごとの枠                         | 標準プランは無制限、[Customized V2](https://rustdesk.com/pricing#custom2)はライセンスされた同時接続枠 |
| ライセンスの基準                   | シート単位／チャネル単位               | [ログインユーザー数＋管理対象デバイス数](https://rustdesk.com/pricing)                                 |

正確なプランの構成と現在の価格は[rustdesk.com/pricing](https://rustdesk.com/pricing)をご覧ください。

## プランによって異なる同時接続

支払うのは、認可されたログインユーザー（通常は技術者）と管理対象デバイスの分です。標準プランには無制限の同時接続が含まれるため、障害対応中に3人のエンジニアが同時に3つの顧客サイトで作業していても、それはいつもの業務の一コマにすぎず、追加の課金が発生する出来事ではありません。これまで同時セッション数をやりくりしたり、チャネル数に合わせてチームの動きを調整したりしてきたなら、標準プランではその制約がなくなります。

同時接続数をライセンスで定めるのは[Customized V2](https://rustdesk.com/pricing#custom2)だけです。RustDeskの[同時接続の定義](https://github.com/rustdesk/rustdesk/wiki/FAQ#concurrent-connections)では、同時接続とは操作中の制御側デバイス、つまり「チャネル」のことです。1台の技術者端末が5つのセッションタブを開いていても1チャネル、3台の技術者端末が同時に操作していれば3チャネルです。また、Customized V2ではユーザーまたはデバイスグループに割り当てられたデバイスだけが管理対象デバイスとしてカウントされるため、単発のサポートで接続したマシンはカウントも無効化もされません。[何が管理対象デバイスとしてカウントされるか](/ja/blog/what-counts-as-a-managed-device-ja)をご覧ください。

## ブランド化し、アクセス制御をかける

Server Proは、MSPにセルフホスト型のWebコンソールと、役割の異なる3つの制御を提供します。[アクセス制御](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/permissions/)は、ユーザーとデバイスグループのルールによって、どの技術者がどのデバイスに接続できるかを決めます。各デバイスは1つのデバイスグループに所属し、ユーザーグループとデバイスグループの権限は累積されます。共有アドレス帳は技術者向けにエントリを整理するもので、アクセスの境界ではありません。[コントロールロール](https://rustdesk.com/docs/ja/self-host/rustdesk-server-pro/control-role/)は、技術者がセッション中にできる操作を制限します。カスタムクライアントジェネレーターとLDAP/OIDC SSOはBasicプランから利用できます。

ブランド化したクライアントが重要なのは、顧客がインストールするのが、ベンダーではなく自社の名前、ロゴ、サーバー設定を備えたツールになるからです。アクセス制御を使えば、各技術者が接続できる範囲を、担当する顧客サイトのデバイスグループに限定できます。

## サーバー側のデータの所在地を管理する

セルフホストすれば、MSPはID/ランデブー、リレー、コンソール、保存されるデバイスのデータをどこで動かし、誰が運用するかを選べます。規制の厳しい業種の顧客では、これが決め手になることも少なくありません。ただし、これはデプロイメント上の管理手段であり、コンプライアンス認証ではありません。直接セッションはエンドポイント間を流れるため、[リモートデスクトップのデータ主権とGDPR](/ja/blog/remote-desktop-data-sovereignty-gdpr-ja)で解説しているように、エンドポイントの所在地と経路も整理してください。

## 自社の条件で試す

商談の予約をしなくても、今日からRustDeskを評価できます。

- **空いているVMにServer OSSを立ち上げる。** ライセンス料も有効期限もないため、費用をかける前に実際の顧客対応のワークフローを検証できます。
- **ブランディングやアクセス制御が必要になったら、** [rustdesk.com/pricing](https://rustdesk.com/pricing)でプランを比較し、[sales@rustdesk.com](mailto:sales@rustdesk.com)に現在の評価条件をお問い合わせください。
- **検証の時間がとれないなら。** まずRustDeskの動作を見るか、[RustDeskのYouTubeチャンネル](https://www.youtube.com/@rustdesk)の解説動画をご覧ください。

顧客が増えるのに合わせて、<strong>[いつでもアップグレード](/ja/blog/upgrade-rustdesk-license-mid-subscription-ja)</strong>できます。有効期限はアップグレード日から丸1年に延長され、支払い済みの残存分が充当されます。まずは[rustdesk.com/pricing](https://rustdesk.com/pricing)からどうぞ。
