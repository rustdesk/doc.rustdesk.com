遠端桌面詐騙是一種詐騙手法：犯罪者說服您安裝合法的遠端存取軟體，接著利用它取得您電腦的控制權——藉此掏空銀行帳戶、竊取資料，或植入惡意軟體。這些工具本身，正是 IT 部門每天都在使用的同一批軟體。真正讓它變成詐騙的，是另一端的人是誰，以及對方是如何說服您讓他們進來的。

本文刻意採取廠商中立的立場。任何遠端桌面產品都可能被這樣濫用，RustDesk 也不例外。本文的目標，是協助您辨識這種詐騙模式、學會拒絕，並在萬一已經中招時知道如何補救。

## 遠端存取詐騙如何運作

[美國聯邦貿易委員會（FTC）](https://consumer.ftc.gov/articles/how-spot-avoid-and-report-tech-support-scams)與 [FBI](https://www.fbi.gov/how-we-can-help-you/scams-and-safety/common-frauds-and-scams/tech-support-scams) 都描述了一套驚人一致的詐騙劇本：

1. **誘餌上鉤。** 彈跳視窗警告「您的電腦已遭感染」，或是您接到一通意外的來電、電子郵件或簡訊。發送者會冒充您信任的名號——Microsoft、Apple、Amazon、您的銀行、公用事業公司，甚至是您自家公司的 IT 部門。
2. **刻意營造急迫感。** 對方會說您的帳號已遭入侵、病毒正在擴散、有一筆退款等您領取，或是您的服務即將被停止。根據 FTC 的說法，詐騙者「希望您在還來不及思考之前就採取行動」，催促您盡快行動的壓力正是重點所在。
3. **安裝工具。** 對方會要求您下載「免費的遠端支援軟體」，好讓他們「修復」問題。這確實是真實存在的軟體——而這正是騙局如此逼真的原因。
4. **授予存取權。** 對方會要求您唸出螢幕上的連線代碼或密碼，或是核准連入的工作階段。光有裝置 ID 通常不足以取得控制權；分享代碼或接受請求，才是對方進入的那一刻。
5. **取得控制權。** 對方會假裝執行病毒掃描、開啟您的網路銀行網站、轉走資金，或開立新帳戶。[FBI 波士頓分局](https://www.fbi.gov/contact-us/field-offices/boston/news/press-releases/fbi-warns-public-to-beware-of-tech-support-scammers-targeting-financial-accounts-using-remote-desktop-software)曾警告，詐騙者會利用這項存取權開立虛擬貨幣帳戶，並將受害者銀行帳戶中的真實存款提領一空。

這樣的損失絕非紙上談兵。在同一份 FBI 警告中，調查人員描述了美國緬因州一對夫婦的遭遇：一個彈跳視窗要他們撥打「Fidelity」的電話號碼，對方接著指示他們安裝遠端桌面軟體，讓假冒的「Microsoft」與「Fidelity」人員監看他們的帳戶——最終損失約 **110 萬美元**。

## 常見警訊

幾乎每一起遠端存取詐騙，都至少會觸動以下其中一條警戒線：

- **未經請求的主動聯繫。** 陌生人主動找上門，說要修復一個您根本沒回報過的電腦問題。FTC 對此說得很直白：該機構及其退款管理單位「絕不會要求您用禮品卡付款」，也絕不會「要求取得您裝置的遠端存取權」。Microsoft、Apple 或您的銀行同樣不會這麼做。
- **附上電話號碼的彈跳視窗。** 真正的安全性警告，絕不會要您撥打某支支援專線。那支號碼屬於詐騙者。
- **施壓與急迫感。** 「現在立刻照做，否則您將失去一切」是一種操控手法，不是正常的支援流程。
- **要求安裝軟體並唸出代碼。** 這是整起詐騙運作的核心機制。任何誠實的陌生來電者都不需要您這麼做。
- **話題轉向金錢。** 要求以禮品卡、電匯、加密貨幣付款，或聲稱「退款」不知為何多給了，需要您「退回」差額。
- **在您登入時全程不掛電話。** 對方就是想親眼看著您輸入網路銀行的帳號密碼。

## 正規支援 vs. 詐騙

|                | 正規的遠端支援                         | 詐騙                               |
| -------------- | -------------------------------------- | ---------------------------------- |
| 由誰發起       | 您主動聯繫對方，撥打您自行查到的號碼   | 對方毫無預警地主動聯繫您           |
| 問題本身       | 您先前已經回報過的問題                 | 對方聲稱「發現」並告知您的問題     |
| 急迫程度       | 事先排定時間，不慌不忙                 | 「現在立刻行動，否則後果自負」     |
| 連線代碼       | 您在知情的情況下，自己選擇分享         | 被逼著快速唸出代碼                 |
| 付款方式       | 如有收費，走正常請款流程               | 禮品卡、電匯、加密貨幣、「退款」   |
| 網路銀行存取   | 修電腦從來不需要                       | 這才是對方真正的目的               |

## 萬一已經讓詐騙者取得存取權，該怎麼辦

如果您在通話當下或事後才發現自己被騙，請盡快依序採取以下行動：

1. **中斷網路連線。** 立刻關閉 Wi-Fi 或拔掉網路線，切斷對方的工作階段。
2. **解除安裝對方要您安裝的遠端存取應用程式。** 如果不確定該怎麼做，可以請信任的在地技術人員協助。
3. **掃描惡意軟體。** 執行完整的防毒掃描；如果牽涉到存有敏感資料的電腦，可考慮請專業人員清理。請假設對方可能已在系統中留下東西。
4. **改用另一台可信任的裝置變更密碼**——優先處理電子郵件與網路銀行，接著處理所有共用相同密碼的帳號。
5. **聯絡您的銀行與發卡機構。** 通報詐騙、詢問能否撤銷轉帳，並持續留意未經授權的交易。
6. **保護您的身分。** 如果您透露了個人資料，請向美國三大徵信機構 Equifax、Experian 與 TransUnion 申請詐騙警示或信用凍結。
7. **向您所在地區的主管機關報案。** 在**美國**，請向 FTC 的 [ReportFraud.ftc.gov](https://reportfraud.ftc.gov) 與 [FBI IC3](https://www.ic3.gov) 檢舉。在美國以外的地區，請聯絡當地警方與相關的詐騙通報機關，並向銀行詢問當地的身分保護措施。

## 如何預防

預防的關鍵，就在於養成以下幾個習慣：

- **絕不因為對方主動聯繫，就依照要求安裝遠端軟體。** 方向要反過來：如果您需要協助，請自行查到廠商的官方電話並主動撥打。
- **絕不對您沒有主動聯繫的對象唸出連線代碼。**
- **把彈跳視窗上的電話號碼一律當成假的。** 直接關閉瀏覽器——必要時強制結束——而不是撥打那支電話。
- **放慢腳步。** 急迫感是詐騙者的工具。真正的機構一定會讓您先掛斷電話，再回撥確認。
- **找人聊聊。** 這類詐騙特別容易鎖定年長者與處於壓力之下的人。向家人隨口問一句「這聽起來對勁嗎？」，往往就能打破騙局的魔咒。

## 遠端桌面工具在其中扮演的角色

值得再強調一次：軟體本身不是壞人。遠端桌面工具是 IT 團隊維持全世界電腦正常運作的方式，同一款應用程式是救命工具還是攻擊武器，取決於握在誰手上。歸咎於某一款產品其實搞錯了重點——真正的防線在於掌控您讓誰進來。

話雖如此，如果您以專業身分*提供*遠端支援，有幾項架構上的選擇可以降低風險。自架 RustDesk 伺服器，可讓 ID/連線協調與中繼服務在您掌控的基礎架構上執行。誰能連線，就由您自己的控管機制決定：落實基本的[無人值守存取安全設定](/zh-tw/blog/rustdesk-unattended-access-setup-zh-tw)，使用高強度且不重複的固定密碼與連線雙重驗證；在受控裝置上加入 IP 或 ID 白名單；並使用 Server Pro 依使用者與裝置群組設定的[存取控制](https://rustdesk.com/docs/zh-tw/self-host/rustdesk-server-pro/permissions/)。此外，由於 RustDesk 是[開源](https://github.com/rustdesk/rustdesk)的，您或資安團隊都能確切稽核它在您的電腦上做了什麼。

不過，以上這些都無法讓 RustDesk——或任何其他工具——完全免疫於詐騙。只要使用者被誘騙安裝用戶端並唸出代碼，在任何平台上都可能受害。架構能降低某些風險，但永遠無法取代上述所有警告核心的那條簡單原則：不要把電腦的控制權交給主動聯繫*您*的人。
