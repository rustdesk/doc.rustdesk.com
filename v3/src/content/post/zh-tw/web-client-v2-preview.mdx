2024 年 10 月，我們推出了 **RustDesk Web 用戶端 V2 預覽版**。它帶來更強的解碼能力、更好的國際鍵盤支援、同時支援圖片與文字的剪貼簿，以及檔案傳輸。在瀏覽器的限制範圍內，我們致力讓 Web 版的功能與使用體驗和桌面用戶端保持一致。

您可以造訪 https://rustdesk.com/web 使用 RustDesk Web 用戶端 V2 預覽版。若您希望透過 V2 存取自己的伺服器，請依照[文件](https://rustdesk.com/docs/zh-tw/self-host/rustdesk-server-pro/faq/)設定 WebSocket Secure（WSS）支援，透過 HTTPS/WSS 反向代理連接埠 21118/21119 上的 ID 與中繼 WebSocket 後端。當反向代理對外開放 TCP 443 時，請讓這些後端連接埠只在內部使用。

```nginx
    location /ws/id {
        proxy_pass http://localhost:21118;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws/relay {
        proxy_pass http://localhost:21119;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
```

Web 用戶端也已**整合至 RustDesk Server Pro**，您可以從自己的伺服器 `https://rustdesk.yourcompany.com/web` 提供服務，而不必依賴公用版本。

## 在自己的伺服器上使用 Web 用戶端的兩種方式

- **公用 Web 用戶端（`rustdesk.com/web`）連到您的伺服器。** 您可以使用 RustDesk 代管的 Web 用戶端，並將它連到自己的 ID/中繼伺服器，但需要自行完成設定：瀏覽器需要 WebSocket Secure（WSS）與正確的 CORS 標頭才能連到您的伺服器。詳見 [Web 用戶端的 WSS 與 CORS 設定](https://github.com/rustdesk/rustdesk/wiki/FAQ#wss-and-cors-setup-for-web-client)。
- **自架 Web 用戶端（由 Server Pro 在 `https://your-server/web` 提供）。** Web 用戶端已[整合至 RustDesk Server Pro](https://github.com/rustdesk/rustdesk/wiki/FAQ#is-web-client-integrated-into-rusetdesk-server-pro)，因此可以從您自己的伺服器執行，而不必使用公用版本。自架 Web 用戶端**不包含在入門方案**中——方案規模必須滿足 **（使用者數 × 10）+ 裝置數 ≥ 400**（例如 10 位使用者／300 台裝置、30 位使用者／100 台裝置，或 20 位使用者／200 台裝置）。自架的 Web 用戶端也可以[自訂](https://github.com/rustdesk/rustdesk/wiki/FAQ#how-to-customize-self-hosted-web-client)。

無論選擇哪種方式，Web 用戶端都是**控制端**：您可以在瀏覽器分頁中操控其他裝置，但瀏覽器分頁無法作為無人值守的被控主機。

立即試用 [Web 用戶端](https://rustdesk.com/web)，目前的部署細節請參閱 [Server Pro 文件](https://rustdesk.com/docs/zh-tw/self-host/rustdesk-server-pro/)。各瀏覽器的剪貼簿權限與鍵盤處理方式不同，請測試您團隊實際使用的瀏覽器。
