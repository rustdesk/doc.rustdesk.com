RustDesk Server Pro 1.5.0 现已发布，带来了设备组和用户级访问控制。

## 更新日志

- 新增设备组及其访问控制规则
- 新增用户级访问控制
- 新增设备组策略
- 新增可排序表格
- 当电子邮件地址匹配时，OIDC 登录会关联到现有账户
- 设备 ID 中允许使用 `-`（连字符）
- 修复 OIDC 名称为 `null` 时登录失败的问题

设备组是 RustDesk Server Pro 1.5.0 的一项新功能。此前，RustDesk 注重简洁，没有引入设备组，而是仅依靠用户组管理 ACL（访问控制列表）。但在大型组织中，这种方式会让访问权限配置变得繁琐。因此，我们在 1.5.0 中加入了设备组和用户级 ACL。现在可以对设备进行分组并为这些组应用策略，从而显著改善大规模环境中的设备管理。

RustDesk Server Pro 原先只支持用户组，本次更新后也支持设备组。每台设备除了关联一个用户外，还可以分配到一个设备组。这样你就能基于设备组实施更多策略，例如限制或授予对特定设备的访问。此外，本版本还引入了用户级 ACL，可在用户组之外为单个用户设置权限，让访问管理更加灵活、可控。

**更新（2026 年）：** 后续的 Server Pro 版本新增了用于会话内权限的[控制角色](https://rustdesk.com/docs/zh-cn/self-host/rustdesk-server-pro/control-role/)。用户组和设备组的权限会累加，因此任一方都可以授予访问权限。当前的配置方式请参阅[访问控制文档](https://rustdesk.com/docs/zh-cn/self-host/rustdesk-server-pro/permissions/)。
