您打开 AnyDesk，只是想连接自己家里的电脑，或者帮家人解决点问题，却收到提示说**检测到商业用途**，或者需要为专业用途购买许可证。AnyDesk 的[服务条款](https://anydesk.com/en/terms)规定免费版仅供个人非商业使用，并允许对这条边界进行强制执行。如果判定有误，请先走官方审核流程；如果确实是商业用途，请比较付费或自托管的选择，而不是设法规避条款。

## 如何解决 AnyDesk 账户的“检测到商业用途”提示

对于确实属于个人非商业用途的用户，AnyDesk 提供了官方[白名单申请](https://anydesk.com/en/commercial-use)通道。大致流程如下：

1. **记下您的 AnyDesk 地址（ID）**——即打开客户端时显示的编号——涉及的每台设备都要记，包括您 _发起_ 连接的设备，以及您 _连接到_ 的设备。
2. **打开 AnyDesk 官方的[商业用途/白名单申请表单](https://anydesk.com/en/commercial-use)。**
3. **如实描述您的实际使用情况**——例如“我只是用它帮父母处理家里的电脑”，或者其他能真实反映您使用场景的说明。
4. **提交后等待 AnyDesk 审核。** 如需跟进，请使用当前表单上提供的联系方式。

接下来会出现两种结果之一：AnyDesk 确认您属于个人用途并将您加入白名单，或者判定您的使用属于商业用途，提示继续保留。只有在提示确属误判时，申诉才有意义——如果您的使用本来就是商业用途，无论申诉结果如何、采用什么变通手段，都改变不了这一点。我们也不会介绍网上流传的那些非官方“删除配置文件”重置技巧：这类做法是在 AnyDesk 授权条款的边缘打擦边球，也改变不了您的使用是否构成商业用途。

### 这里究竟什么算“商业用途”

根据 AnyDesk 自己的条款，**个人用途**是非专业性质的使用——访问自己的设备，或帮助亲友，且不涉及任何直接或间接的报酬。**商业（专业）用途**——白名单申请不会、也不应该放行的情况——包括：

- 为客户或同事提供支持
- 任何形式的远程办公，包括仅仅连接工作电脑或查收工作邮件
- 在从事贸易、商业活动或职业工作过程中建立的任何连接
- 管理服务器，或为组织管理多台设备
- 任何您因此直接或间接获得报酬的使用

如果您的使用属于以上任何一种，AnyDesk 的提示就是准确的，长久之计是选用一款许可条款与您实际工作方式相符的工具——本文下面会展开介绍。

## 为什么 AnyDesk 会标记“商业用途”

AnyDesk 没有公布官方的判定阈值，因此第三方帖子中提到的具体连接次数、会话时长、设备数量上限或超时时间，都应视为未经证实的说法，而不是可以依赖的规则。其他远程访问产品也有同样的授权区分，包括 [TeamViewer 的商业用途判定](/zh-cn/blog/teamviewer-commercial-use-detected-zh-cn)；对于确属商业性质的工作，这条警告并不是需要绕过的技术故障，请比较当前的付费套餐或替代方案，而不是去追逐非官方的重置方法或续期传闻。

如果申诉不适用，您有两条长久可行的路：购买商业许可证，或者换用一款根本没有商业用途“绊线”的工具。

## 核心区别：没有免费版的商业用途判定机制

AnyDesk 没有公开检测器的算法，而且它既支持直连会话也支持中继会话，因此一条警告并不能证明您的屏幕媒体流经过了 AnyDesk 中继。**RustDesk Server OSS（免费社区服务器）完全没有商业用途判定机制**：依据其许可协议，个人和商业使用都免费。RustDesk 的客户端和 Server OSS 采用 [AGPL 协议](https://github.com/rustdesk/rustdesk)；Server Pro 是商业的专有自托管服务器软件，唯一的限制来自您购买的套餐。两者都可以让您自己运行连接协调服务和中继服务。

## 自托管 RustDesk 能为支持团队带来什么

授权条件事先约定：Server Pro 套餐按登录用户和受管设备计数，标准套餐包含无限并发连接；只有 [Customized V2](https://rustdesk.com/pricing#custom2) 按设定数量授权。您可以随时[升级](/zh-cn/blog/upgrade-rustdesk-license-mid-subscription-zh-cn)：升级时抵扣原许可证剩余已付价值，并将到期日延长至升级日起一年。针对客户支持工作，Pro 还提供自托管的 Web 控制台、按用户和设备组设置的[访问控制](https://rustdesk.com/docs/zh-cn/self-host/rustdesk-server-pro/permissions/)，以及从 Basic 套餐起提供的自定义品牌客户端生成器和 [LDAP/OIDC SSO](https://rustdesk.com/docs/zh-cn/self-host/rustdesk-server-pro/ldap/)。

## 接下来怎么做

如果这次提示只是误判，上面的白名单申请就是解决办法。如果您的使用确实属于商业用途，请先在 Server OSS 上试点：重现当初触发提示的工作流程——同样的技术人员、终端、无人值守会话和支持工作量——并在决定年度购买之前，核算好两个授权维度（登录用户数和受管设备数）。无论考虑哪种替代方案，用于工作之前都请先阅读它的许可协议——可以免费下载，并不自动意味着允许商业使用。如需 Pro 评估条款，请联系 [sales@rustdesk.com](mailto:sales@rustdesk.com)。
