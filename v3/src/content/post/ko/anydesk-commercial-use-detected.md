집에 있는 PC에 접속하거나 가족을 도우려고 AnyDesk를 열었는데 **상업적 사용이 감지되었다**는 경고나 업무용으로 쓰려면 라이선스가 필요하다는 메시지를 받으셨나요? AnyDesk [이용약관](https://anydesk.com/en/terms)은 무료 버전을 개인적인 비상업적 용도로 한정하고, 이 경계를 강제할 수 있도록 하고 있습니다. 분류가 잘못되었다면 공식 검토 절차부터 시작하세요. 실제로 상업적인 용도라면 약관을 피하려 하지 말고 유료 또는 자체 호스팅 선택지를 비교하세요.

## AnyDesk 계정에서 "상업적 사용 감지" 문제 해결하기

AnyDesk는 실제로 개인적이고 비상업적인 용도로 쓰는 사용자를 위해 공식 [화이트리스트 신청](https://anydesk.com/en/commercial-use) 절차를 제공합니다. 절차는 대략 다음과 같습니다.

1. **AnyDesk 주소(ID)를 기록하세요.** 클라이언트를 열면 표시되는 번호이며, 접속을 _하는_ 기기와 접속을 _받는_ 기기 등 관련된 모든 기기의 주소가 필요합니다.
2. **AnyDesk 공식 [상업적 사용/화이트리스트 신청 양식](https://anydesk.com/en/commercial-use)을 여세요.**
3. **실제 사용 방식을 솔직하게 적으세요.** 예를 들어 "부모님 댁 PC를 도와드리는 용도로만 씁니다"처럼, 실제로 하고 있는 일을 있는 그대로 설명하면 됩니다.
4. **제출하고 AnyDesk의 검토를 기다리세요.** 후속 문의가 필요하면 현재 양식에 안내된 연락 경로를 이용하세요.

결과는 둘 중 하나입니다. AnyDesk가 개인적 사용임을 확인하고 화이트리스트에 등록하거나, 상업적 사용이라고 판단해 표시를 유지합니다. 이의 신청은 표시가 실제로 오탐지였을 때만 도움이 됩니다. 실제로 상업적인 용도라면 결과도, 편법도 그 사실을 바꾸지 못합니다. 인터넷에 떠도는 비공식 "설정 파일 삭제" 초기화 요령도 여기서는 안내하지 않습니다. 이런 방법은 AnyDesk 라이선스 약관을 피해 갈 뿐, 실제 사용이 상업적인지 여부와는 아무 관련이 없습니다.

### 여기서 실제로 "상업적 사용"에 해당하는 것

AnyDesk 약관에 따르면 **개인적 사용**은 본인 소유 기기에 접속하거나 친구와 가족을 돕는 등 직간접적인 대가가 없는 비업무 용도입니다. 화이트리스트 신청으로 해결되지 않고, 해결되어서도 안 되는 **상업적(업무) 사용**에는 다음이 포함됩니다.

- 고객, 클라이언트, 동료 지원
- 업무용 컴퓨터에 접속하거나 업무 이메일을 확인하는 것을 포함한 모든 형태의 원격 근무
- 거래, 사업, 직업 활동 과정에서 이루어지는 모든 접속
- 서버 관리 또는 조직을 위한 여러 기기 관리
- 직접적이든 간접적이든 대가를 받는 모든 사용

이 중 하나라도 해당한다면 AnyDesk의 표시는 정확하며, 근본적인 해결책은 실제 업무 방식에 맞는 라이선스의 도구를 쓰는 것입니다. 이 가이드의 나머지 부분에서 이를 다룹니다.

## AnyDesk가 "상업적 사용"을 표시하는 이유

AnyDesk는 공식 감지 기준치를 공개하지 않으므로, 제3자 게시글에 나오는 구체적인 연결 횟수, 세션 시간, 기기 수 제한, 시간 제한은 믿을 수 있는 규칙이 아니라 검증되지 않은 정보로 보아야 합니다. 같은 라이선스 구분은 [TeamViewer의 상업적 사용 분류](/ko/blog/teamviewer-commercial-use-detected-ko) 등 다른 원격 접속 제품에도 있습니다. 실제로 상업적인 업무라면 이 경고는 우회해야 할 기술적 버그가 아니므로, 비공식 초기화 방법이나 갱신 후기를 좇기보다 현재 유료 플랜이나 대안을 비교하세요.

이의 신청이 해당하지 않는다면 지속 가능한 길은 두 가지입니다. 상용 라이선스를 구매하거나, 상업적 사용 감지 기능이 아예 없는 도구로 옮기는 것입니다.

## 핵심 차이: 무료 등급의 상업적 사용 분류 기능이 없음

AnyDesk는 감지 공식을 공개하지 않으며 직접 세션과 릴레이 세션을 모두 지원하므로, 경고가 떴다고 해서 화면 데이터가 AnyDesk 릴레이를 거쳤다는 증거는 아닙니다. **RustDesk Server OSS(무료 커뮤니티 서버)에는 상업적 사용 분류 기능이 전혀 없습니다.** 라이선스에 따라 개인 용도와 업무 용도 모두 무료로 쓸 수 있습니다. RustDesk 클라이언트와 Server OSS는 [AGPL 라이선스](https://github.com/rustdesk/rustdesk)이며, Server Pro는 구매한 플랜으로만 한도가 정해지는 상용 독점 자체 호스팅 서버 소프트웨어입니다. 두 제품 모두 랑데부 서비스와 릴레이 서비스를 직접 운영할 수 있습니다.

## 자체 호스팅 RustDesk가 지원 팀에 주는 것

라이선스는 미리 정해 둔 대로입니다. Server Pro 플랜은 로그인 사용자와 관리 대상 기기를 기준으로 산정되며, 표준 플랜에는 무제한 동시 연결이 포함되고 [Customized V2](https://rustdesk.com/pricing#custom2)만 정해진 수를 라이선스로 제공합니다. [업그레이드는 언제든](/ko/blog/upgrade-rustdesk-license-mid-subscription-ko) 할 수 있으며, 라이선스가 업그레이드한 날로부터 1년 뒤로 연장되고 남은 결제 금액은 크레딧으로 반영됩니다. 고객 지원 업무를 위해 Pro는 자체 호스팅 웹 콘솔과 사용자별·기기 그룹별 [접근 제어](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/permissions/)를 제공하며, Basic 플랜부터는 커스텀 브랜딩 클라이언트 생성기와 [LDAP/OIDC SSO](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/ldap/)도 제공합니다.

## 다음 단계

표시가 오탐지였다면 위의 화이트리스트 신청이 해결책입니다. 실제로 상업적인 용도라면 먼저 Server OSS로 파일럿을 진행하세요. 표시를 유발했던 업무 흐름(같은 기술자, 엔드포인트, 무인 세션, 지원 물량)을 그대로 재현하고, 연간 구매를 결정하기 전에 두 가지 라이선스 기준(로그인 사용자와 관리 대상 기기)의 규모를 산정하세요. 어떤 대안을 검토하든 업무에 도입하기 전에 라이선스를 확인하세요. 무료로 내려받을 수 있다고 해서 상업적 사용이 자동으로 허용되는 것은 아닙니다. Pro 평가 조건은 [sales@rustdesk.com](mailto:sales@rustdesk.com)으로 문의하세요.
