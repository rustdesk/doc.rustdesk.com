AnyDesk 갱신 가격이 올랐다면 현실적인 선택지는 세 가지입니다. 갱신하면서 협상하거나, 다른 관리형 서비스로 옮기거나, 인프라를 직접 통제하는 자체 호스팅 모델로 전환하는 것입니다. 이 가이드는 실제로 무엇이 올랐는지 확인하고, 이용 권한을 같은 기준으로 맞추고, RustDesk로 전환할 때의 손익분기점을 계산하는 방법을 보여 줍니다. 기능과 배포 방식의 차이는 [RustDesk vs AnyDesk](/ko/blog/rustdesk-vs-anydesk-ko)를 참고하세요.

## AnyDesk 갱신 가격이 정해지는 방식

AnyDesk는 사용자, 관리 대상 기기, 동시 연결 허용량에 추가 옵션을 더한 연간 결제 등급을 판매합니다. 클라우드 요금제는 벤더가 운영하는 연결 조정을 사용하며, Ultimate는 고객이 직접 운영하는 On-Premises 어플라이언스도 제공합니다. 등급 경계, 허용량, 요율은 벤더가 정하므로 갱신 때 그중 무엇이든 바뀔 수 있습니다.

[현재 공개된 요금제](https://anydesk.com/en/pricing)를 날짜가 명시된 갱신 견적과 비교하세요.

## 실제로 무엇이 인상되었는지 확인하기

무엇이든 비교하기 전에 이전 청구서, 갱신 견적서, AnyDesk의 현재 요금제 페이지를 나란히 놓고 통화, 세금, 청구 주기, 할인, 라이선스 사용자 수, 동시 세션 수, 관리 대상 기기 수, 네임스페이스, 추가 옵션을 같은 기준으로 맞추세요. 총액이 커진 원인은 요율 인상, 할인 종료, 사용량 증가, 패키지 재구성일 수 있으며, 흔히 여러 원인이 겹칩니다. 두 견적서의 실질 연간 비용과 정확한 이용 권한을 기록해 두어야 막연한 느낌이 아니라 근거 있는 "가격 인상" 수치를 확보할 수 있습니다.

## 자체 호스팅으로 바뀌는 비용 항목

RustDesk에서는 ID/랑데부 서비스와 릴레이 서비스를 직접 운영하며, Server Pro를 쓰면 콘솔과 저장된 관리 데이터도 직접 운영합니다([이것이 비용 구조를 바꾸는 이유](/ko/blog/why-self-host-remote-desktop-software-ko)). RustDesk 클라이언트와 RustDesk Server OSS(무료 커뮤니티 서버)는 AGPL 라이선스이며, Server OSS에는 라이선스 비용이 없습니다. Server Pro는 중앙 관리 기능을 더하는 상용 독점 자체 호스팅 서버 소프트웨어입니다. 비용은 **연간 라이선스와 인프라·운영 비용**으로 바뀝니다. 갱신되는 것은 사용량을 측정하는 클라우드 서비스가 아니라 라이선스입니다.

RustDesk 라이선스는 **로그인 사용자와 관리 대상 기기 단위**로 산정됩니다. [업그레이드](/ko/blog/upgrade-rustdesk-license-mid-subscription-ko)는 셀프 서비스 포털에서 언제든 구매할 수 있으며, 라이선스 만료일이 업그레이드한 날로부터 1년 뒤로 연장되고 현재 라이선스의 남은 결제 금액은 업그레이드 비용에서 차감됩니다. 표준 요금제에는 무제한 [동시 연결](https://rustdesk.com/pricing)이 포함되며, 정해진 수의 동시 연결을 라이선스하는 요금제는 [Customized V2](https://rustdesk.com/pricing#custom2)뿐입니다. 정확한 라이선스 가격과 요금제 등급은 [rustdesk.com/pricing에서 확인하세요](https://rustdesk.com/pricing).

## 데이터를 직접 소유하세요 — 그리고 클라이언트를 감사하세요

비용만이 팀이 떠나는 이유는 아닙니다. 자체 호스팅하면 랑데부 서버, 릴레이, 콘솔, 관리 대상 기기 데이터가 실행되는 위치를 직접 고를 수 있습니다. 다만 그것만으로 엔드포인트 간 직접 트래픽이 한 국가 안에 머문다고 보장되거나 배포가 규정을 준수하게 되지는 않으므로, 전체 데이터 흐름은 [데이터 주권 가이드](/ko/blog/remote-desktop-data-sovereignty-gdpr-ko)에서 정리하세요. 또한 RustDesk 클라이언트는 **[AGPL](https://github.com/rustdesk/rustdesk) 라이선스의 오픈소스**이므로, 코드를 읽고 엔드포인트에서 무엇을 하는지 검증할 수 있습니다. (기존 벤더의 보안을 따로 따져 보고 있다면 [AnyDesk는 안전한가요?](/ko/blog/is-anydesk-safe-ko)를 참고하세요.)

MSP와 IT 팀을 위해 Server Pro는 자체 호스팅 콘솔, 기기 그룹, 공유 주소록, 사용자·기기 그룹 단위 [접근 제어](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/permissions/)를 더하며, Basic 요금제부터 커스텀 클라이언트 생성과 LDAP/OIDC SSO를 제공합니다. 더 큰 환경을 위해서는 RustDesk가 [대규모 기기 운영 계획](/ko/blog/rustdesk-scale-50000-200000-devices-ko) 가이드를 공개하고 있습니다.

## 갱신 후 협상 vs 전환: 손익분기점

갱신 견적이 갑자기 오르면 실질적인 선택은 두 가지이며, 반사적으로 대응하기보다 두 가지 모두의 비용을 계산해 볼 가치가 있습니다.

**갱신 후 협상하기.** 가장 빠른 방법입니다. 마이그레이션도 재교육도 필요 없고, 팀이 이미 익숙한 도구를 그대로 쓰며, 때로는 인상 폭을 낮출 수도 있습니다. 다만 할인은 일시적일 수 있고, 내년에 다시 같은 협상 테이블로 돌아오게 됩니다. 인상 폭이 크지 않거나, 프로젝트가 한창 진행 중이거나, 전환 비용이 유난히 큰 경우에 알맞은 선택입니다.

**전환하기.** 마이그레이션 시간, 약간의 재교육, 자체 서버 구축이라는 실질적인 초기 비용이 들며, 이를 숨기지 않겠습니다. 이 일회성 비용으로 얻는 것은 반복 지출이 여러분 자신의 인프라 비용과 라이선스 비용으로 바뀌는 구조입니다.

**손익분기점.** 대안의 연간 총비용이 더 낮다면, 단순 손익분기 연수는 **일회성 마이그레이션 비용 ÷ 연간 총비용 절감액**입니다. 양쪽 벤더의 라이선스와 추가 옵션, 호스팅, 백업, 대역폭, 모니터링, 관리자 시간을 모두 포함하세요. 일회성 비용은 한 번으로 끝나지만, 반복되는 인상은 갱신할 때마다 되풀이됩니다. 연간 절감액이 0이거나 마이너스라면 이 가정에서는 비용 기준의 회수가 없으므로, 통제권이나 거버넌스 측면의 이점은 따로 모델링하세요. 갱신이 아니라 "상업적 사용" 경고 때문에 이 글을 찾으셨다면 [그 상황을 다루는 별도 가이드](/ko/blog/anydesk-commercial-use-detected-ko)가 있습니다.

## 비교 가능한 3년 비용 모델 만들기

한쪽의 갱신 견적을 다른 벤더의 진입 가격과 단순 비교하지 말고, 각 선택지를 같은 워크시트에 넣어 비교하세요.

| 비용 항목                           |              AnyDesk 갱신 |                                    자체 호스팅 대안 |
| ----------------------------------- | ------------------------: | --------------------------------------------------: |
| 필요한 라이선스 사용자와 엔드포인트 |        날짜가 명시된 견적 |                      로그인 사용자 + 관리 대상 기기 |
| 필요한 동시 연결 또는 세션          | 요금제 허용량과 추가 옵션 | 표준 요금제는 무제한, Customized V2는 정해진 허용량 |
| 호스팅, 백업, 모니터링, 대역폭      |          보통 SaaS에 포함 |                                    자체 인프라 비용 |
| 배포 및 마이그레이션 작업           |      정책/클라이언트 변경 |          서버 구축, 클라이언트 배포, 접근 권한 매핑 |
| 지속적인 운영 관리                  |            벤더/계정 관리 |                       패치, 인증서, 용량, 사고 대응 |
| 선택 사항: 브랜딩, SSO, 관리자 제어 |       맞는 등급/추가 옵션 |                                맞는 Server Pro 등급 |

같은 36개월을 기준으로 기본 시나리오와 성장 시나리오를 계산하세요. 자체 호스팅이 벤더 클라우드 비용을 줄여 줄 수는 있지만 운영이 공짜는 아닙니다. 의미 있는 결과는 가격 페이지의 가장 작은 숫자가 아니라 _여러분의_ 워크로드에 드는 총비용입니다. 마이그레이션 과정을 자세히 보고 싶다면 [자체 호스팅 TeamViewer·AnyDesk 대안](/ko/blog/self-hosted-teamviewer-alternative-ko)을 참고하세요.

## 자체 인프라에서 직접 비교해 보세요

대표 엔드포인트와 지원 세션으로 Server OSS 파일럿을 시작하세요. 배포 시간, 연결 성공률, 릴레이 대역폭, 유지 관리 작업을 기록한 뒤, 관리 기능이 필요하다면 [Server Pro 라이선스](https://rustdesk.com/pricing)를 더하세요. 현재 Pro 평가 조건은 [영업팀](mailto:sales@rustdesk.com)에 문의할 수 있습니다.

다음에 또 가격 인상 이메일이 오더라도 더 유리한 위치에서 협상할 수 있습니다. 직접 운영하는 서버, 감사할 수 있는 클라이언트, 언제든 돌아갈 수 있는 무료 Server OSS, 그리고 표준 요금제에서 무제한 동시 연결을 제공하는 Server Pro 라이선스가 있기 때문입니다.
