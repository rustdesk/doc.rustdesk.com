2024년 10월, **RustDesk 웹 클라이언트 V2 프리뷰**를 공개했습니다. 더 강력한 디코딩, 향상된 국제 키보드 지원, 텍스트뿐 아니라 이미지까지 지원하는 클립보드, 그리고 파일 전송을 제공합니다. 브라우저가 부과하는 제약 안에서 웹 버전의 기능과 사용자 경험을 데스크톱 클라이언트와 맞추기 위해 노력했습니다.

https://rustdesk.com/web 에서 RustDesk 웹 클라이언트 V2 프리뷰를 이용할 수 있습니다. V2로 자체 서버에 접속하려면 [문서](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/faq/#8-id-서버와-릴레이-서버에-websocket-secure-wss-지원을-추가하여-모든-플랫폼에서-안전한-통신을-가능하게-하십시오)에 따라 WebSocket Secure(WSS) 지원을 구성하고, 포트 21118/21119의 ID 및 릴레이 WebSocket 백엔드를 HTTPS/WSS를 통해 프록시하세요. 리버스 프록시가 TCP 443을 노출한다면 이 백엔드 포트는 내부에만 두세요.

```nginx
    location /ws/id {
        proxy_pass http://localhost:21118;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws/relay {
        proxy_pass http://localhost:21119;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
```

웹 클라이언트는 **RustDesk Server Pro에도 통합**되어 있어, 공개 웹 클라이언트에 의존하지 않고 자체 서버의 `https://rustdesk.yourcompany.com/web`에서 제공할 수 있습니다.

## 자체 서버에서 웹 클라이언트를 사용하는 두 가지 방법

- **공개 웹 클라이언트(`rustdesk.com/web`)를 자체 서버에 연결하는 방법.** RustDesk가 호스팅하는 웹 클라이언트를 자체 ID/릴레이 서버에 연결해 사용할 수 있지만, 설정은 직접 해야 합니다. 브라우저가 자체 서버에 도달하려면 WebSocket Secure(WSS)와 올바른 CORS 헤더가 필요합니다. [웹 클라이언트용 WSS 및 CORS 설정](https://github.com/rustdesk/rustdesk/wiki/FAQ#wss-and-cors-setup-for-web-client)을 참고하세요.
- **자체 호스팅 웹 클라이언트(Server Pro가 `https://your-server/web`에서 제공).** 웹 클라이언트는 [RustDesk Server Pro에 통합](https://github.com/rustdesk/rustdesk/wiki/FAQ#is-web-client-integrated-into-rusetdesk-server-pro)되어 있어, 공개 웹 클라이언트가 아니라 자체 서버에서 실행됩니다. 웹 클라이언트 자체 호스팅은 **입문 요금제에는 포함되지 않으며**, **(사용자 수 × 10) + 기기 수 ≥ 400**을 충족하는 규모의 요금제가 필요합니다(예: 사용자 10명/기기 300대, 사용자 30명/기기 100대, 사용자 20명/기기 200대). 자체 호스팅 웹 클라이언트는 [사용자 지정](https://github.com/rustdesk/rustdesk/wiki/FAQ#how-to-customize-self-hosted-web-client)도 할 수 있습니다.

어떤 방식을 선택하든 웹 클라이언트는 **컨트롤러** 역할을 합니다. 브라우저 탭에서 다른 기기를 제어할 수는 있지만, 브라우저 탭이 무인 호스트로 동작할 수는 없습니다.

지금 [웹 클라이언트](https://rustdesk.com/web)를 사용해 보고, 현재 배포 방법은 [Server Pro 문서](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/)를 참고하세요. 브라우저마다 클립보드 권한과 키보드 처리 방식이 다르므로, 팀에서 쓰는 브라우저로 테스트하세요.
