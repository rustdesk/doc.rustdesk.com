RustDesk Server Pro 1.5.0이 출시되었습니다. 기기 그룹과 사용자 단위 접근 제어를 제공합니다.

## 변경 사항

- 기기 그룹과 해당 접근 제어 규칙 추가
- 사용자 단위 접근 제어 추가
- 기기 그룹용 정책 추가
- 정렬 가능한 표 추가
- 이메일이 일치하면 OIDC 로그인을 기존 계정에 연결
- 기기 ID에 `-`(대시) 허용
- OIDC 이름이 `null`일 때 로그인에 실패하던 문제 수정

기기 그룹은 RustDesk Server Pro 1.5.0에 새로 추가된 기능입니다. 이전에는 단순함을 우선해 기기 그룹을 도입하지 않고, 접근 제어 목록(ACL) 관리를 사용자 그룹에만 의존했습니다. 하지만 이 방식은 대규모 조직에서 접근 권한 설정을 번거롭게 만들었습니다. 그래서 1.5.0에서 기기 그룹과 사용자 단위 ACL을 도입하기로 했습니다. 이제 기기를 그룹으로 묶고 그룹에 정책을 적용할 수 있어, 대규모 환경의 기기 관리가 크게 개선됩니다.

원래 RustDesk Server Pro는 사용자 그룹만 지원했지만, 이번 업데이트로 기기 그룹도 지원합니다. 각 기기는 사용자와 연결되는 것과 별도로 하나의 기기 그룹에 할당할 수 있습니다. 이를 통해 특정 기기에 대한 접근을 제한하거나 허용하는 등 기기 그룹 기반의 추가 정책을 적용할 수 있습니다. 또한 이번 릴리스는 사용자 그룹뿐 아니라 개별 사용자에게도 권한을 설정할 수 있는 사용자 단위 ACL을 도입해, 접근 관리를 더 유연하고 세밀하게 통제할 수 있게 합니다.

**업데이트(2026년):** 이후 Server Pro 릴리스에서는 세션 내 권한을 위한 [제어 역할](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/control-role/)이 추가되었습니다. 사용자 그룹 권한과 기기 그룹 권한은 누적되므로 어느 쪽이든 접근을 허용할 수 있습니다. 현재 구성 방법은 [접근 제어 문서](https://rustdesk.com/docs/ko/self-host/rustdesk-server-pro/permissions/)를 참고하세요.
